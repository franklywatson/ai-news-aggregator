OpenAI Ships GPT-Live: A Full-Duplex Voice Model That Listens and Speaks Simultaneously

Anthropic Brings Claude Cowork Background Agents to Mobile and Web

Anthropic has expanded Claude Cowork to mobile and web, allowing AI agents to continue working on complex tasks across files, calendars, and messaging apps even when the user's device is offline. The platform now supports scheduled tasks that run autonomously, requesting user approval only when critical decisions arise.

"Moving autonomous agents to persistent background execution on mobile devices normalizes human-agent collaboration, transitioning AI from a reactive chatbot to a proactive, asynchronous worker."

Anthropic's Multi-Agent Orchestration Trick Achieves 96% Performance at Half the Cost

Anthropic has detailed a new Claude Managed Agents architecture where submodels are pinned by field, allowing each sub-agent to cache context independently and drastically cut repeat token spend. This 'plan big, execute small' approach achieves 96% of top model performance while reducing operational costs by roughly 46%.

"Cost-effective context management and sub-agent delegation are the critical unlocks needed to make complex, multi-agent production workflows economically viable for enterprise deployment."

Bun's Million-Line Rust Rewrite Showcases the Power of Coordinated Coding Agents

Jarred Sumner detailed how he used coordinated parallel agents powered by Claude to completely rewrite the Bun JavaScript runtime from Zig to Rust, generating over one million lines of code. The project relied on a sophisticated agent harness featuring dynamic workflows, adversarial review, and a massive test suite for conformance checking.

"This is a landmark case study in agentic engineering, proving that autonomous agents can successfully execute massive, ground-up software rewrites when guided by robust harness engineering and context management."

"This demonstrates a production-ready blueprint for secure multi-agent orchestration in enterprise environments, solving the critical bottleneck of cross-repo automation without compromising security."

Stanford Builds Git-Style Version Control for Live AI Agent Runs

Researchers at Stanford have introduced 'Shepherd,' an open-source tool that applies Git-style version control principles to live AI agent executions. The system allows developers to track, branch, and revert the exact states and actions of autonomous agents during complex, multi-step workflows.

"As agents take on long-horizon tasks, the ability to audit, rewind, and manage their operational state becomes essential for debugging and building reliable multi-agent systems."
