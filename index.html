AI Models & Research

Google Open-Sources Harness², an Agent That Rewrites Its Own Harness

Google Research released Harness², a framework where an agent edits its own system prompt, skills, hooks, and memory while model weights stay frozen. An editor agent proposes changes, a composer diffs trajectories against a baseline, and a reflector saves lessons — yielding gains of 8.4 and 7.5 points on WorkBuddy-Bench and JobBench for Gemini 3.5 Flash.

"Self-improving harnesses without grader models point toward agents that compound their own capability at the orchestration layer, independent of new model releases."

DeepMind Research: Bad User Guesses Cut Agent Success Rates by Nearly Half

The XYEval benchmark shows agents suffer relative performance drops of up to 46.7% when users ask about their attempted solution rather than their real problem, and drops worsen with pedantic users who demand explanations. Simple system-prompt mitigation only partially helps.

"As agents are deployed to real users, sycophancy toward plausible-but-wrong user framing becomes a major reliability and safety bottleneck."

NVIDIA's ASPIRE Hits 99% Success on 80 Robot Tasks Using Agent Skills Instead of Gradients

ASPIRE reframes continual learning as skill refinement: a repo of sensorimotor skills replaces fine-tuned weights, with a panel of coding agents each practicing a different task. With Claude Opus 5.5, it reaches 97–100% across LIBERO-Pro, Robosuite, and BEHAVIOR-1K, and can solve a Rubik's Cube.

"It demonstrates that general-purpose LLMs plus skill libraries can outperform traditional robot learning — a concrete path from coding agents to physical-world autonomy."

Simon Willison Builds a Full RTS Game Almost Entirely With Claude Code

After 12 iterations and 321 agent commits, Battle Drones is a 3D, mobile-friendly RTS with random map generation, adaptive music, multiplayer, and an agent-vs-agent mode where different LLMs battle via tool access. A single 'Make it a LOT more fun' prompt in Claude Code's Ultracode mode ran a thousand simulated playtests overnight to rebalance the game.

"A detailed first-person account of what long-horizon, multi-subagent coding workflows can now deliver in a domain the author knew nothing about — including self-directed playtesting and iteration."

Snyk: Skills and MCP Are Becoming the New npm — With a Security Debt Crisis Attached

Snyk's Manoj Nair argues that agent skills and MCP servers are becoming the standard unit of software composition, but that security hasn't kept pace: for every vulnerability fixed, roughly eight new ones are introduced as AI-accelerated delivery outpaces review.

"As the agent ecosystem standardizes on skills and MCP, supply-chain security for agent capabilities becomes the next critical infrastructure problem."

Tenex on Enterprise Agents: Only 5% of Firms Have Non-Engineering Agents in Production

The applied-AI firm, now 75 people serving Fortune 2000 clients, reports that while 90% of enterprises have rolled out Claude or Codex and ~50% have coding agents, only about 5% run production agents outside engineering. Their 'MetaHarness' keeps plans, decisions, and agent logs checked into Git so context is never trapped in someone's head — and engineer output has roughly doubled this year.

"One of the clearest data points yet on the real diffusion gap between raw model capability and deployed enterprise agents, plus a working blueprint (context-in-repo) for closing it."
