AI Models & Research

OpenAI ships GPT-6.2 Astra and Sol, cutting frontier prices 20%

OpenAI introduced GPT-6.2 Astra, its new frontier model, alongside the efficient GPT-6.2 Sol. Astra costs $8/$40 per million tokens — matching Claude Fable 5.2 — with cached input dropping to $0.40, a major discount for long-running agentic sessions. Early reception is mixed: Astra trails Fable 5.2 on some benchmarks, and reviewers like Theo Browne report it can derail long autonomous tasks by pausing to ask users unanswerable internal implementation questions.

"The price war is now centered on agentic workloads, where cached-token economics dominate cost. But Astra's subagent-orchestration quirks highlight that long-horizon autonomy remains an unsolved interaction-design problem."

Google's Tasks agent goes free — and can now make phone calls and purchases

Google rebranded its Spark agent as Tasks and made it free across the US, Japan, Korea, Canada, Australia, and India, powered by the new Gemini 4 Hydrogen model. Tasks can call businesses, negotiate appointments, buy items via the new Agent Payments Protocol (AP2) with Mastercard and Visa, and manage email, calendar, and shopping across 60+ connected apps, running inside an isolated per-user VM.

"This is one of the largest consumer deployments of general-purpose agents to date, and it pushes agentic commerce standards (AP2) and security isolation into the mainstream. How websites and businesses adapt to assistant-driven traffic will shape the next web."

Cloudflare declares itself a 'neolab' with System One decision models

Cloudflare launched Clef, a clone of TypeSafe AI's Jev decision model, and Clairic, a new 'extraction' System One model that pulls typed values from unstructured input in a single forward pass. The company says it will also produce reasoning models via post-training, framing model-building as a natural extension of its infrastructure business and a hedge against closed-source model risk.

"Fast, cheap System One models routing work away from LLMs could become a core pattern in agent orchestration — and Cloudflare building them signals infrastructure players competing at the model layer too."

Osmo claims human-level 'AI nose' with its smell foundation model

Osmo says its foundation model for smell, trained on 10 million human labels and 800 million scent tokens, matches average humans at detecting and discriminating odors and junior perfumers at creating them — reportedly beating in-house perfumers at a major consumer goods company. Applications span fragrance design, counterfeit detection, and disease-carrying insect repellents, though critics note heavy reliance on human sensory panels.

"It's a rare demonstration that the foundation-model playbook can extend beyond text and vision into chemical senses, with concrete commercial traction already."

Numerical bugs found in KL and Jensen-Shannon divergence — core tools of RL and distillation

Following Barron et al.'s discovery of bugs in softmax and cross-entropy, new research shows forward and reverse KL divergence, generalized JSD, and Monte Carlo entropy estimates suffer similar rounding and cancellation errors when distributions are nearly equal. The paper proposes numerically stable reformulations relevant to knowledge distillation, RL, and proximal methods.

"These operations sit inside nearly every RLHF and distillation pipeline that trains today's agents; silent numerical errors here could subtly corrupt training objectives across the field."

Developer Tools & Infrastructure

GitHub open-sources the Agent Host Protocol for cross-device agent sessions

GitHub detailed the Agent Host Protocol (AHP), an open standard that lets agent sessions started in one place — VS Code, the Copilot app, a phone, or a cloud sandbox — continue seamlessly elsewhere. Built on URI-identified channels with reducer-based state, AHP has two independent host implementations (TypeScript in VS Code, Rust at GitHub) and client libraries in six languages, with hooks for MCP and OpenTelemetry.

"As agents work for hours or days, session portability becomes as fundamental as LSP was for editors. AHP could become the shared protocol that decouples agents from any single app, and its MCP-style escape hatches invite ecosystem adoption."

high

Simon Willison releases the 'external sandbox' pattern for coding agents

Simon Willison and Prime Radiant published three open-source sandbox servers — v86/WebAssembly, Apple Containers, and Microsoft Quicksand — that let Claude Code, Codex, and Pi execute code in an isolated environment separate from the agent itself. Each includes an allow-list network proxy and a credential-replacement mechanism so agents can make authenticated calls without ever seeing secrets.

"Prompt injection and accidental damage are the top risks of autonomous coding agents. This pattern makes running local or lower-trust models substantially safer and is immediately usable today."

Claude Code gains an interactive iOS Simulator pane — including iPhone Duo fold poses

Claude Code Desktop's new iOS Simulator pane, now in public beta, lets Claude install, tap through, and visually verify an app in a simulated iPhone or iPad while the developer watches and can intervene. It supports folding the iPhone Duo simulator through closed, half-open, and open poses, and lets Claude load Xcode's agent skills for layout work.

"Closing the perception loop — agent builds, runs, sees, and self-verifies — is a meaningful step toward genuinely autonomous mobile development, and shows how model vendors are shipping harness features rather than just models."

GitHub and Microsoft's agentic scanner shipped fixes, not findings, to open-source maintainers

In a pilot using Codename MDASH — Microsoft's multi-model agentic scanning harness — thousands of raw findings across six major open-source projects were filtered by an AI triage agent and human review into 99 verified private reports with suggested fixes; maintainers have already fixed 55. Projects like Caddy cleared all 22 reports within a week, with some fixes shipping in 15 minutes.

"It's a working template for responsible agentic security research: verify privately, arrive with patches, and don't flood maintainers. It also demonstrates multi-agent triage pipelines producing production-grade outcomes."

Kent C. Dodds rebuilt a skill with 1M installs as a hybrid design, using deterministic software for mechanical work and the AI model only for judgment calls. The result is faster, cheaper, and more accurate.

"This is a practical architectural pattern for anyone building agent skills — offloading non-judgment work from the model dramatically cuts cost and latency while improving reliability."

Least Privilege for AI Agents Includes Token Placement

A often-skipped layer of least-privilege for agents: controlling where in an HTTP request tokens are allowed to appear. Query strings can leak credentials into access logs, proxies, or browser history, so Kody defaults new credentials to headers only.

"As AI agents handle more credentials, token placement discipline becomes a real security surface — this is an actionable hardening step most teams haven't considered."
