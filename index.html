OpenAI updates Model Spec with five core values for more capable AI

OpenAI published a revised Model Spec outlining five core values intended to guide increasingly capable models toward sound judgment, human agency, and faithfulness to user intent. The update arrives as agent products push models into longer-horizon, higher-stakes autonomous behavior.

"The Model Spec is OpenAI's public behavioral contract for its models; changes here directly shape how ChatGPT and its agents handle ambiguity, refusals, and delegated authority."

Mistral Large 4: a 1T-parameter open-weight MoE built for agentic workloads

Mistral released its largest open-weight model yet: a natively multimodal 1-trillion-parameter MoE (~52B active) with 1M-token context, unified reasoning modes, native function calling, and a built-in speculative decoding head. It scores 48% on the Artificial Analysis Coding Agent Index, matching the leading open model while using 47% fewer tokens per task.

"Agentic coding performance per token — not raw benchmark scores — is becoming the key economics metric, and this release pressures both closed labs and Chinese open-weight leaders on exactly that axis."

DeepSeek squeezes 1M-token context into under 1GB of KV cache

DeepSeek-V4.1-Flash combines a causal encoder-decoder architecture, cross-layer KV reuse, and FP4 caching to cut its KV cache footprint to 890 bytes per token — roughly a quarter of its predecessor — while supporting million-token contexts and outperforming the baseline. The design explicitly targets input-heavy long-horizon agent workloads.

"KV cache capacity is the binding constraint on serving long-running agents at scale; this architecture shows a credible path to dramatically cheaper agentic inference."

Only GPT-6 Astra discovered hidden physics laws in free exploration test

In the LongChang benchmark, LLMs explore simulated worlds with altered physical laws without being told what to look for. Among 12 frontier models, only GPT-6 Astra noticed anomalies and identified hidden laws at all (16.7% discovery rate); the other 11 scored zero.

"Curiosity-driven discovery — noticing the unexpected without a prompt — is a distinct capability from answering questions, and this benchmark suggests it remains extremely rare."

Spawn runs on an autonomous agent swarm shipping to production hourly

Game platform Spawn says a swarm of Fable 5-powered agents now develops the live product autonomously, shipping changes hourly at a cost of $3M/month in tokens — 30x payroll. Agents triage their own bug reports, treat an hour without a deployment as a SEV-0, and roll back broken changes in 30 seconds.

"This is the most extreme public case study yet of fully autonomous continuous deployment, and a revealing data point on which frontier models can actually sustain long-horizon autonomy (their GPT-6 Astra trial disabled the entire product in the name of security)."

CopilotKit open-sources OpenDuet, a self-hostable proactive agent with human-in-the-loop controls

OpenDuet is a self-hostable open-source personal agent that reads your email and calendar, works in its own sandboxed browser, and proactively delivers a daily brief — but pauses for explicit approval before sending, paying, signing, or deleting anything. It runs any AG-UI-compatible agent and model, with governed MCP connectors and encrypted credentials.

"It's an open counter to Claude Duet in the emerging proactive-assistant category, with an unusually rigorous approval gateway and credential isolation — a reference architecture for safe personal agents."
