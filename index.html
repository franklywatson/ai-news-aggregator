AI Models & Research

MIT Researchers Stranded Claude on a Virtual Island — and It Started Playing

MIT CSAIL researchers left copies of Claude Opus 4.7 alone in a virtual world for 30 hours with no task instructions. The agents invented games like basketball and 'the floor is lava,' built stone drawings of constellations, and — crucially — agents that had 'played' outperformed fresh copies on later tasks, hinting at playful learning as a third training paradigm beyond supervised and reinforcement learning.

"If agents can build reusable world knowledge through undirected exploration, it points to a new way to make long-horizon autonomous agents more adaptable without human demonstrations or rewards."

AI Agent Solves 49 of 50 Expert Physics Problems for Under $3 Each

The TheoPhysEval benchmark tested AI agents on 50 unpublished, research-level theoretical physics problems. GPT-6-Astra running in Codex achieved 98% accuracy at under $3 per problem — and in several cases corrected errors in the experts' own reference answers.

"Off-the-shelf agents harnessed in Codex can now autonomously perform calculations that would take human experts a full day, signaling that frontier research workflows are becoming automatable."

Claude Code Team Reveals Continuous, Agent-First Code Review

Anthropic says Claude now writes roughly 90% of Claude Code's own code, and the team has replaced end-of-road human review gates with continuous agent review — most changes are already reviewed and fixed by Claude before a human sees them. Human attention is reserved for higher-level questions.

"This is a detailed, public blueprint from a frontier lab for how 'did a human read the code?' stops being the quality bar, and what checks replace it in an agentic SDLC."

Context Engineering's Unanswered Question: Is Your CLAUDE.md Any Good?

Maria Gorinova argues context engineering still lacks measurement tools — teams write CLAUDE.md files and system prompts with no way to evaluate whether they actually improve agent behavior. The talk outlines approaches to making context files empirically testable.

"As coding agents absorb more of the development loop, unmeasured context files become a silent quality bottleneck; rigorous evaluation of agent context is an emerging discipline."

Linus Torvalds Used an LLM on the Linux Kernel — and a Test Harness Found Three Real Bugs

Torvalds called anti-AI rules 'utterly stupid' after using an LLM to make the kernel's assoc_array code readable; a subsequent test harness surfaced three genuine bugs in the refactored code.

"The maintainer of the world's most consequential open-source project endorsing LLM-assisted kernel work is a strong signal for agent-assisted development in even the most conservative codebases."

Industry & Applications

The Web Is Closing Its Doors to AI Agents

Yelp, Delta, Chase, Schwab, Amtrak, and others are actively blocking AI agents from OpenAI, Meta, xAI, and Instinct, citing licensing, security, and ad-revenue concerns. The trend threatens the core promise of general-purpose web agents and is fueling legal battles like Amazon v. Perplexity.

"Agent usefulness depends on web access; a widening patchwork of blocks could fragment the agent ecosystem into walled partnerships and push the industry toward MCP-style authenticated integrations instead of open browsing."

Anthropic Embeds METR Watchdogs With 'Employee-Like' Access

METR, a nonprofit evaluator, now has a team inside Anthropic with access to hardware and internal systems, and can publish findings without Anthropic's approval — the first implementation of Amodei's proposal for embedded external auditors. OpenAI has endorsed the idea but not yet announced plans.

"Independent, resident evaluation is the labs' leading concrete answer to safety concerns about agentic AI, and its success or failure will shape whether regulation follows this model."
