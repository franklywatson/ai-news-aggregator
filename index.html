AI Models & Research

Open-weight 27B model can read neural network weights raw — no tools required

Simon Willison replicated the 'Sparks of Weight-Space Programming' paper and found Qwen 3.8 27B running locally on a laptop can identify what a policy network was trained to do purely from raw floating-point weights, without code execution. He cautions that breathless commentary about the end of source code overstates the finding, and critics have challenged the paper's weight-editing claims.

"If models can genuinely inspect and modify other models' weights, it opens a path to AI that debugs and improves other AI systems — though the current evidence suggests it's an impressive reasoning feat, not a paradigm shift."

Tokyo lab's AI agents run a full quantum physics experiment — and catch their own measurement drift

Researchers demonstrated an autonomous laboratory where LLM-based agents review each other's work, generate and reject research questions, and redesign experiments when results look suspicious. The agents investigated quantum spin ensembles in diamond, detected signal drift that invalidated an initial result, and revised the protocol until it met their own acceptance criteria.

"This is a concrete example of multi-agent orchestration performing the full scientific loop — hypothesis, theory, experiment, and self-correction — with built-in peer review that catches unreliable conclusions."

Open-sourced sparse attention runs 72x faster at 10-million-token context

Latent Sparse Attention clusters keys in a learned latent space so queries score cluster hierarchies instead of every key, sustaining accuracy at ultra-long context. At 10M tokens it speeds up prefill by up to 72x and decode by over 42x, with a distillation variant that works on pre-trained models.

"Long-horizon agentic workloads are context-starved by quadratic attention costs; a practical 10M-token attention method directly enables the marathon sessions agents increasingly need."

ChatGPT now handles queries equal to 20% of Google search volume, OpenAI claims

OpenAI said search-like queries through ChatGPT now equal roughly 20 percent of Google's search volume, alongside 1.2 billion weekly users. The figure is OpenAI's own estimate based on its definition of search-like activity rather than an audited market-share comparison.

"Query behavior is visibly migrating from classic search to conversational AI, pressuring the ad economics that fund the web — a shift Google's own earnings this week showed is not yet paying for itself."

Developer Tools & Infrastructure

Claude API gains server-side conversation caching, cutting agent latency 35%

Anthropic's new message threads feature, now in public beta, lets agents send only new messages per turn instead of resending full conversation history. For Claude Code sessions carrying 500K–1M tokens, median time to first token drops about 35%; threads are held encrypted in memory and expire after 5 minutes.

"Long-running coding and computer-use agents are bottlenecked by resending massive context every turn — this is targeted infrastructure engineering for exactly that pain point, enabled by default for Claude Code users."

"This puts the Codex agent harness into a fully governed enterprise runtime — a signal that agent orchestration is becoming packaged cloud infrastructure rather than DIY tooling."

Apple opens Siri AI to third-party apps with multi-step actions and on-screen awareness

In iOS 27.3 rolling out this week, developers can integrate Siri AI into all apps via App Intents, letting the assistant draw on personal context, process natural language, use on-screen awareness, and chain multiple actions — like checking an order before arranging delivery. Apple simultaneously warned in its annual filing that autonomous agents could exceed permissions or conceal actions.

"Apple is finally turning Siri into a genuine cross-app agent, which puts agentic UX in front of a billion-plus users — while its own risk disclosure highlights how hard it is to ship agents safely."

Google's AI search is boosting queries — but they monetize worse than the ads they replace

Alphabet's search revenue growth slowed to 12% as AI Mode queries grew strongly but monetized at lower rates than traditional searches, contributing to a 14% share drop despite roughly $200 billion in planned AI infrastructure spending. An early study found ChatGPT ad traffic generated 64% less retail revenue per session than Google Search ads.

"The gap between AI usage growth and AI monetization is now visible in real earnings, and it frames the economics behind the entire industry's agent and chatbot buildout."

NYT sues Brave, calling it a 'distributor of stolen content' to AI companies

The New York Times and other publishers sued Brave Software, alleging the browser bypasses paywalls by default and resells scraped news content via its search API to AI firms including Anthropic, Perplexity, Mistral, xAI, and Cohere — earning an estimated $100 million while publishers got nothing. The suit claims direct, contributory, and vicarious infringement plus DMCA violations.

"This extends the training-data copyright wars to the retrieval layer that agents depend on, potentially disrupting the real-time content pipelines powering AI search and assistants."
