Anthropic Overhauls MCP Specification for Stateless Enterprise Scaling

The Model Context Protocol (MCP) has received its largest update yet, transforming its core from a bidirectional stateful protocol into a request/response stateless protocol. This shift removes major dependency barriers, allowing developers to build significantly more reliable and scalable agent-to-tool pipelines.

"By solving core reliability and state limitations, MCP is cementing its position as the universal standard for connecting enterprise data and tools to AI agents at scale."

GitHub Copilot App Introduces Stacked Sessions for Multi-Step Agentic Coding
