Claude Haiku 5.5 matches GPT-6 Luna pricing at 10x cheaper than its predecessor

Anthropic's new fast model is priced at $0.10/$0.50 per million tokens up to 100k tokens, exactly matching OpenAI's GPT-6 Luna while reportedly beating it on benchmarks. Developer Tools & Infrastructure

MCP's OAuth authentication is a structural mismatch for enterprise agents

A rigorous Doyensec analysis of MCP's auth architecture, paired with field experience from Teleport, identifies serious gaps: no per-tool authorization, no mTLS in the core spec, no audit trail standard, and an OAuth trust model designed for consenting humans rather than non-deterministic LLMs that select scopes at runtime. The 2026 MCP roadmap defers most enterprise security to extensions, leaving production deployments to fill the gaps themselves.

"As MCP becomes core infrastructure for agent tool access, its unresolved authorization model is the biggest security risk facing enterprise agent deployments."

high

One in three GitHub pull requests now involves an AI agent

GitHub reports that AI-agent participation in pull requests jumped from under 10% to 33% in a year, and most code could be agent-written within two years. To keep secret protection scaling, GitHub built a ModernBERT classifier that evaluates candidate secrets in under 2ms and could more than double the number of leaked credentials blocked before push.

"Hard data on agent-written code proliferation, plus a security response that assumes humans won't read most code — the operating assumption for the agentic era."

"A charming example of the growing agent-observability tooling layer, built entirely on the standardized transcripts coding agents now emit."

MIT Technology Review: the gap between humanoid robot demos and reality

A deep report examines why the same AI techniques behind LLMs have not yet translated into general-purpose robots, despite viral demos. Researchers including Yann LeCun argue language-style training can't handle high-dimensional physical data, and point to world models — with Physical Intelligence's π0.7 showing the first hints of compositional generalization — as the more promising path. Meanwhile, deployed humanoids still do narrow tasks in controlled environments, and home robots remain roughly a decade out.

"A useful corrective to robotics hype, and a signal that the next breakthrough may come from world models rather than scaling current VLA approaches."

Google, Meta, and Isomorphic Labs pour $300M into a 'virtual cell'

Google DeepMind, Meta, and Isomorphic Labs are jointly investing $300 million in the Chan-Zuckerberg Biohub's effort to build a computational 'virtual cell' for disease research. The project aims to simulate cellular biology well enough to accelerate drug discovery and therapeutic design.

"Frontier labs are converging on biology as AI's biggest application arena, following the success of protein-structure prediction with full-cell simulation."
