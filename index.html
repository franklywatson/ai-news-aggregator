Claude Opus 5.5 and GPT-6 Sol/Luna Ignite a Frontier Price War

Anthropic and OpenAI released flagship mid-tier models within an hour of each other, with GPT-6 Luna dropping to $0.10/$0.50 per million tokens — one of OpenAI's cheapest ever — and Claude Opus 5.5 cutting prices 20% with a 60% cache-read reduction. Willison's hands-on testing also flagged that Opus 5.5 at 'max' thinking can over-reason until it exhausts its 128K output limit and fails to respond.

"Aggressive cache-price cuts directly lower the cost of long agentic conversations, where 90%+ of input tokens are cached, reshaping the economics of running coding agents like Claude Code and Codex."

Communicating Agent Teams Beat Solo Agents 4-to-1 on Hard Reasoning

New research shows that a team of k agents communicating via a shared directory at test time matches the success rate of 4k independent agents on ARC-AGI-3, with gains compounding at scale. Teams even beat best-known human results on MNIST classifier compression, though the advantage requires sufficient compute and clear progress signals.

"This is some of the strongest evidence yet that multi-agent coordination — not just parallel sampling — is the right scaling lever for hard, novel problem-solving tasks."

Xiaomi's 1T-parameter (42B active) natively omnimodal model debuts at the top of the open-weights intelligence index under an MIT license, with the final RL run costing roughly $2.6–3M. The company is also open-sourcing its RL environments, training recipes, and agent tooling across coding, cyber, and general-agent domains.

"Open RL environments may become as strategically important as pretraining corpora were in the last cycle — and a non-'Tiger' Chinese lab shipping frontier open weights with full training tooling changes who can build competitive agents."

CodeMidas Turns Open-Source Code Into RL Training Environments for Coding Agents

Xiaomi's agentic pipeline converts implemented functionality in existing codebases into 5,545 executable RL environments across 23 languages, using source code as the only input. Training on these tasks improved MiMo-V2.5 across all five benchmarks tested, including +11.7% on DeepSWE and +17% on whole-program construction.

"A scalable, automated recipe for generating agentic RL environments addresses one of the key bottlenecks in training better coding agents."

"It demonstrates that the 'decision model' paradigm Jev popularized is reproducible cheaply and openly, accelerating adoption of cheap single-step classification/routing calls inside larger agent loops."

Developer Tools & Infrastructure

Google Open-Sources AX: Kubernetes for Autonomous Agent Workloads

AX is a declarative, high-throughput orchestrator for running billions of autonomous agent tasks on Kubernetes clusters, with primitives for sandboxed execution, pre-wired Git/MCP workspaces, network fencing via egress allowlists, and suspend/resume checkpointing. It treats agents as a new workload class — neither stateless microservices nor batch jobs.

"As agents move to production, dedicated orchestration infrastructure with isolation, cost control, and state management becomes essential — AX is a credible open-source answer from Google at exactly the moment this layer is being defined."

OpenAI Overhauls Prompt Caching for GPT-6 With Breakpoints and Diagnostics

GPT-6 introduces higher cache hit rates, new diagnostics, explicit cache breakpoints, and finer-grained controls designed to reduce latency and cost. Combined with Luna's near-free cached input ($0.01/M), long-running agent loops get dramatically cheaper.

"Cache behavior is the hidden driver of agent economics — improvements here directly enable longer, richer agentic sessions without runaway costs."

Together.ai Adds Canary Rollouts for Zero-Downtime Model Upgrades

Together's rollout engine migrates live traffic between model deployments via gated canary steps, with metric gates that caught a 137% p95 latency regression at 10% traffic in a live demo and automatic pausing rather than blind rollback. Blue-green and rolling strategies share the same health-gate machinery.

"As teams ship new models into agent pipelines weekly, safe staged cutover with latency/error gates becomes core production infrastructure."

TypeSafe's Diogo Almeida Explains Jev and the Case Against RLHF

In a wide-ranging interview, the InstructGPT co-author lays out why Jev optimizes for 'intelligence per dollar' via RLCD (calibrated decisions) rather than RLHF or RLVR, why coding agents are trapped by the 'tyranny of the KV cache', and his vision for multi-agent systems that share labeled state instead of giant prompts. Jev is already processing a trillion tokens a day.

"The most detailed articulation yet of a genuinely alternative model paradigm — one that could reshape how coding agents, sub-agents, and agent swarms coordinate state."

Rabbit Pivots From Failed Hardware to a Cloud-Powered Agentic OS

Rabbit's OS3 'agentic operating system' runs in the cloud but operates locally across Windows, Mac, and Linux, automatically selecting devices, files, apps, and AI models needed for a task across up to five linked devices. The company has stopped manufacturing the R1 and is building a new 'cyberdeck' device running OS3.

"A vendor-neutral, multi-device agent layer that orchestrates across your own models and machines is an early test of whether general-purpose personal agents can escape single-ecosystem lock-in."
