Terminal-RSI: A 27B Agent That Rewrites and Retrains Itself With No Human Input

Researchers demonstrated a terminal agent built from Qwen3.8-27B that alternates recursive self-rewriting of its own verified trajectories with policy refinement, reaching 86.5% on Terminal-Bench 2.1 without human intervention in the loop. "Recursive self-improvement in agentic systems is the capability regulators and safety researchers fear most; a reproducible open recipe moves it from theory to practice."

Developer Tools & Infrastructure

Claude Code Is Accidentally Committing Passwords and API Keys to Public GitHub Repos

Security researchers at Apiiro found over 100,000 cases of Claude Code's local settings file — which stores approved shell commands verbatim, including embedded secrets — being uploaded to public repositories, with over 1,100 containing real credentials across 63 organizations. Claude Code sometimes commits the file itself without user input, and removed secrets can persist in forks.

"As coding agents gain autonomy over git operations, they're creating a new, systemic secret-leakage surface that existing gitignore hygiene doesn't cover."

high

OpenCode Browse Lets Coding Agents Use Your Real Browser, Logins Included

OpenCode shipped an MCP server plus Chromium extension that lets agents drive your actual browser — with your existing sessions, tabs, and extensions — opening background tabs via Playwright and handing tabs back for logins, 2FA, or payments. It works with Claude Code, Cursor, Codex, Zed, and other MCP clients.

"Giving agents authenticated access to real web sessions removes the biggest friction in browser automation, while also concentrating enormous security trust in the agent harness."

Simon Willison Gave Claude Code Ears — and It Triangulated a Mystery Beep to 40cm

Using Claude Code Cloud and then Fable 5.2 in Claude Code, Willison had an agent design and build 'Beep Locator,' a multi-device acoustic triangulation system that coordinated five devices over WebSockets, hot-swapped its own listener code, and located a dying carbon-monoxide detector. The agent independently found and applied a 2007 BeepBeep research paper to solve the problem.

"A compelling demonstration that coding agents can perceive and act in the physical world through improvised sensor networks — agents building their own instrumentation is a genuinely new capability pattern."

Anthropic: Tell Fable 5.2 the Codebase Is Its Own — It Refactors More

Anthropic's official prompting docs reveal that Fable 5.2's behavior changes sharply based on stated code ownership: saying 'this codebase is yours' made the model merge duplicated code five times more often than leaving ownership unstated. The finding is part of Anthropic's published prompt-engineering guidance for the new model.
