AI Models & Research

GPT-6.2 Designs Lab-Validated Proteins Using Pure Reasoning and Code

OpenAI reports that GPT-6.2, guided by natural-language prompts, generated protein minibinders that were synthesized and confirmed to bind five drug targets including PD-L1 and VEGF-A — 35 of 322 candidates were positive in wet-lab tests with partner Onava. The model also outperformed specialized tools like RFdiffusion and DiffDock on motif scaffolding and docking benchmarks, though it still lags badly on full structure prediction.

"A general-purpose frontier model matching or beating specialized biology models on design tasks signals a major shift in how computational biology pipelines may be built, pending independent replication."

Together Shows Cheap Distillation Can Patch a Small Model's Blind Spots

Together.ai distilled Kimi-K3.1-Pro's Lao translation ability into Qwen3.8-27B for $260 using LoRA fine-tuning on ~3,800 teacher translations, reaching 93% of the teacher's score while preserving the student's Thai ability. The post offers a repeatable playbook for fixing narrow 'jagged intelligence' gaps in small models, including techniques for avoiding regressions in adjacent skills.

"This is a practical, low-cost template for teams patching specific weaknesses in open-weight models rather than waiting for the next frontier release."

Developer Tools & Infrastructure

MCP Grows Up: Skills, Background Tasks, Elicitation, and File Transfers

Anthropic extended the Model Context Protocol with public-beta Skills (server-published workflow playbooks loaded on demand), generally available Tasks for long-running background operations, Elicitation for mid-workflow user approvals, and an upcoming File Uploads extension that bypasses the model's context window. Tool search already cuts multi-server context usage by over 85%, and the ecosystem reports 700M+ monthly SDK downloads.

"These extensions push MCP from simple tool calls toward full autonomous workflow orchestration, and the context-saving mechanisms directly address the biggest practical constraint in multi-agent systems today."

Claude Artifacts Become Installable Mac and Windows Apps

Anthropic's new 'Install as app' beta turns Claude artifacts into standalone desktop applications with their own icons, windows, menu-bar integrations, global shortcuts, and connector access — no packaging or code signing required. Permissions are version-scoped (every update re-prompts) and span three tiers up to full computer access, though Anthropic performs no app review before installation.

"This collapses the gap between AI-generated tools and shipped software, effectively giving Claude a lightweight Electron-replacement path — while raising real trust questions around unreviewed generated apps with filesystem access."

Together Open-Sources Hurdle for Evaluating Coding Agents Against Your Platform

Hurdle is an open-source npm library that runs Claude Code and Codex against real tasks on your API, scoring runs via code checks, guards that block dangerous API calls, and an LLM judge. Sandboxed runs route all agent traffic through a local proxy that keeps your real API keys out of the sandbox while monitoring every request.

"As agents become a primary interface to developer platforms, systematic evals across models, harnesses, and conditions are essential — Hurdle fills a real gap in agent-testing infrastructure."

GitHub Turns Legacy Modernization Methodology Into a Copilot Agent Skill

A detailed GitHub walkthrough shows an evidence-first process for modernizing legacy applications — building an evidence inventory, choosing the least disruptive treatment per component, and defining honest regression safety levels — and encodes it as a reusable 'doc-and-modernize' Copilot agent skill. The method was validated on applications from a Node.js game to a large Java ERP suite.

"It's a strong example of encoding architectural judgment as agent skills that enforce procedure while leaving policy decisions with humans — a pattern likely to spread across engineering orgs."

Survey: 76% of Devs Generate AI Code Faster Than They Can Verify It

Sonar's survey of 1,000+ developers found that AI now writes or assists 65% of committed code — hitting the two-year projection in one year — but 53% of developers now spend more time reviewing than creating code, up from 18%. Only 39% always check AI-generated code before committing, down from 48% last year.

"The verification bottleneck is now the dominant constraint on AI coding value, and the data shows manual review practices are slipping just as agent-authored code volume explodes."

Amazon in Talks to End Its Block on Meta's Muse Shopping Agent

Amazon has held discussions about allowing Meta's Muse AI agent to shop on its marketplace, potentially ending one of the most prominent agent blocks in commerce, according to Fortune. Talks reportedly center on which products the agent recommends and the impact on Amazon's advertising revenue.

"Amazon was the most visible holdout against agentic commerce; a deal would mark a major inflection in whether AI agents become a mainstream purchasing channel or stay locked out of major marketplaces."

42 State AGs Move to Block Character.AI's Sale of 21M Users' Chat Histories

A bipartisan coalition of 42 state attorneys general is seeking to stop bankrupt Character.AI from auctioning the private chat histories of over 21 million U.S. accounts — including 2.1 million belonging to minors — with no deletion options or limits on downstream use. The leading bidder was only established on November 13th with no disclosed parent company or investors.

"The case is setting early precedents for what happens to sensitive user-conversation data when AI companies fail, a question that will only grow as chatbot usage becomes ubiquitous."

A published Google patent describes 'My Channel,' a system that would generate endless personalized AI videos and ads from users' demographic data, location, and viewing history — including placing digital avatars of users as the protagonist of generated content.
