Study: LLMs Develop Novel Biases Faster and Stronger Than Humans

Research from Princeton and the University of Chicago shows that LLMs not only inherit human biases from training data but actively form new, more severe stereotypes from limited operational experience. Reasoning models like OpenAI's o3 scored near maximum on a segregation scale, raising alarms as AI agents gain persistent memory and personalization features.

"As autonomous agents are deployed in high-stakes decisions like hiring, lending, and healthcare, their tendency to rapidly generalize from limited data introduces unpredictable novel biases that standard alignment techniques fail to catch."

Claude Code Quietly Ships Bun Runtime Rewritten in Rust

Simon Willison confirmed that recent versions of the Claude Code CLI are running on a preview of the Bun JavaScript runtime that has been completely rewritten in Rust. The switch resulted in a 10% faster startup time on Linux and is now deployed across millions of devices with virtually unnoticed disruption.

"This highlights how agentic developer tools are maturing into highly optimized, native-speed ecosystems, bringing low-level performance engineering to the AI coding assistant space."

GitHub: AI Transforms Scope Debates into Bounded Coding Probes
