Developer Tools & Infrastructure

Anthropic Donates Agent Skills Standard to the Linux Foundation's Agentic AI Foundation

Anthropic has handed stewardship of the Agent Skills specification to the Agentic AI Foundation (AAIF) under the Linux Foundation, the same neutral home that already hosts the Model Context Protocol it co-founded with Block and OpenAI. The move keeps Skills vendor-neutral and community-driven. Observers like Simon Willison had predicted the donation since Anthropic first declared Skills an open standard in December.

"Consolidating MCP and Agent Skills under one foundation cementss a neutral, open interoperability layer for agent ecosystems — reducing lock-in across Claude, Codex, and open agent frameworks."

DeepSeek Open-Sources Its Production Inference Engine After Reportedly Earning $22M/Day

DeepSeek released the code behind its DeepInfer serving stack, reportedly processing 155T tokens per day per cluster at roughly 80% margin with an 81-day payback period. The 'deepseek-recipe' release includes Rust libraries and Python bindings for protocol conversion, prompt rendering, and structured output across DeepSeek V4 and V4.1.

"Production-grade serving economics at this scale, now open-sourced, could reset cost expectations for anyone running agentic workloads at high volume."

high

Claude Duet: Anthropic's Proactive Agent That Works While You're Away

Anthropic opened a research preview of Claude Duet, a standalone proactive agent built on Claude Opus 5.5 that monitors connected apps, sends morning briefs, and completes background tasks via its own VM and browser — always checking with the user before sending messages or making payments. It carries over Claude memory, skills, and 6,000+ marketplace connectors, with credentials handled via the Managed Agents design.

"Duet is one of the most complete 'ambient agent' deployments from a major lab, directly testing whether proactive, approval-gated agents can become daily tools for professionals."

high

Claude Mods Flip the Agent Harness to Face the Human

A new analysis frames Claude Mods as an early 'attention interface' — inverting the traditional harness paradigm where the harness faces the machine, toward one where the harness manages the human's attention and context. The piece argues this is a structural shift in how agent orchestration is designed.

"Harness engineering is becoming the key differentiator in agent products; designs that budget human attention, not just tokens, may define the next generation of agent UX."

EAGLE-4 Speculative Decoding Hits 961 Tokens/Second With Up to 3.4x Speedup

EAGLE-4 introduces a flexible drafter that adapts speculation depth to hardware, batch size, and workload, integrating with SGLang, vLLM, and TokenSpeed. It reports up to 3.4x lossless speedup on Qwen3.8-27B and maintains gains even at 512 concurrent requests.

"Lossless inference acceleration that survives high concurrency directly cuts the cost and latency of long-horizon agentic loops, the dominant expense in agent workloads."

OpenAI Agents Find Critical PHP Flaws Affecting 70% of the Web

OpenAI's Patch the Planet program, using GPT-5.6, was one of two parties to independently discover PHP2Shell vulnerabilities in core PHP, which powers roughly 70% of websites. The disclosure was coordinated over two months before public release.

"Autonomous AI systems demonstrating elite offensive-security research capability marks a milestone in AI-driven science — and raises urgent questions about who else can run the same scans."

Canva's First Image Model Plans Designs Before Generating Them

Canva launched Craft, its first in-house image generation model, using a two-stage architecture that plans a design before rendering it — improving legible text and precise object placement at up to 2K resolution and 30+ aspect ratios. Canva plans MCP-based agent integrations and faster variants.

"A plan-then-generate architecture trained on millions of human design templates shows specialized models competing with frontier generalists — and MCP support opens it to agent workflows."

"Healthcare has been the most-cited justification for AI investment; validated diagnostic superiority would force serious rethinking of clinical workflows and regulation."
