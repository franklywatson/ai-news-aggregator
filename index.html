Developer Tools & Infrastructure

Anthropic ships Claude Code Projects: a coordinator agent that runs parallel coding threads in the cloud while you sleep

Claude Code Projects (public beta on Pro and Max) turns a long-running conversation into an agent orchestrator: a coordinator Claude routes work to independent cloud threads that each clone repos, open pull requests, and report back, all sharing project memory and instructions. Threads persist after you close your laptop, with an Overview pane surfacing finished PRs and threads awaiting input.

"This is one of the clearest production examples of hierarchical multi-agent orchestration — coordinator models managing worker agents with shared context, memory, and GitHub integration — shipped to mainstream consumers rather than enterprise pilots."

Claude Code adds AGENTS.md support via open 'mods' — a new way to customize the agent harness

Starting in Claude Code 2.1.277, the agent falls back to AGENTS.md when no CLAUDE.md exists, implemented as a built-in 'mod' — Anthropic's upcoming mechanism for customizing the Claude Code harness, with the source published on GitHub. Developers will be able to build their own custom project-instruction mods on the same foundation.

"Convergence on the AGENTS.md standard plus an extensible harness-mod system signals that agent customization is becoming a first-class platform layer, not just prompt files."

Open-source browser agent finds flights in 7 seconds for under half a cent

Browser Use's 'Jev' agent uses a dynamic indexed action space — one structured decision per round trip pairing an operation with a specific DOM element — to complete a real Google Flights search in 7.1 seconds with ~100 browser protocol calls. No screenshots, no site-specific scripts, and model output never becomes selectors or executable code, keeping the loop safe by construction.

"It demonstrates that harness engineering — structured action spaces rather than bigger models — can cut browser-agent latency and cost by an order of magnitude."

Industry & Applications

Amazon blocks Meta's Muse agent from shopping on its site, igniting the agent-interoperability war

Amazon began blocking Meta's Muse AI assistant from browsing and purchasing on its platform, citing terms-of-use violations and concerns that Muse doesn't identify itself and appears to capture customer credentials. It's the latest salvo in Amazon's effort to keep agentic shopping traffic — and customer data — away from rival AI intermediaries, following its lawsuit against Perplexity and stripped-down confirmation emails.

"The first real standoff over whether websites must accommodate third-party agents will define the economics of agentic commerce and may force standards for agent identification and consent."
