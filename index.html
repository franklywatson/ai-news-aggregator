AI Models & Research

Frontier LLM edits a model's weights directly, fixing math reasoning without any training

In 'Weight-Space Programming,' a frontier model ('Astra') edited just 0.016% of Qwen3.5-0.8B's weights via a Python session — no gradient descent — lifting MATH-500 from 7.9% to 48.1% and largely eliminating the base model's reasoning loops. The edit is published as a bit-exact, hash-verified diff and independently reproduced.

"It suggests models can debug and improve other models at the weight level, opening a cheaper alternative (or complement) to fine-tuning for targeted capability fixes."

high

Study finds coding agents are bad at improving their own harnesses

An empirical study ran Claude Code with a 'retro' skill that reviews completed sessions and proposes harness changes. Of 24 implemented proposals, only a few measurably reduced repeated work, and some added overhead on unrelated issues — most proposals were generic regardless of what actually happened in the session.

"Harness and context engineering is central to agent performance, and this is a rare controlled look at self-evolving harnesses — showing that generating plausible changes is easy, but verifying they help is the hard, unsolved part."

high

Together Compiler uses agent swarms to make inference optimize itself

Together AI's Together Compiler recasts inference optimization as an agentic search problem, using persistent engines and parallel agents to reach up to 2.6x higher throughput in under 24 hours, setting InferenceX state-of-the-art results on MiniMax M3.1-Flash and DeepSeek v4.1-Flash. It runs in production and generalizes beyond LLM serving.

"This is a self-improving loop applied to open-model serving — as agentic traffic shapes and architectures diversify, hand-tuned inference configurations no longer scale, and agent-driven continual optimization becomes the default."

high

Deep Principle open-weights Hydrogen-1.0, a 1M-context science model built on GLM-5.3

Hydrogen-1.0 is a MIT-licensed scientific problem-solving model with a 1-million-token context and 128K output, fine-tuned from GLM-5.3 for derivations, reaction-network exploration, NMR analysis, and experimental planning. Quantized NVFP4 and MXFP4 versions are also released.

"Specialized open-weight models with long context keep narrowing the gap with frontier systems in verticals like chemistry — and the fully permissive license lowers barriers for research-agent builders."

Developer Tools & Infrastructure

OpenAI acquires Pierre Computer Company to expand Codex's code tooling

OpenAI will acquire Pierre Computer Company, folding its tools into Codex for building, understanding, and reviewing code. The deal continues OpenAI's push to make Codex a full-lifecycle development platform rather than a bare coding agent.

"Consolidation around agentic coding platforms is accelerating; acquisitions of tooling layers signal that the harness around the model is becoming the competitive moat."

MCP ships Enterprise-Managed Authorization: one IdP to rule all agent tool access

A new MCP extension lets organizations centrally control access to MCP servers through their existing identity provider, using ID-JAG tokens for single sign-on, policy enforcement, and immediate offboarding revocation — replacing per-user, per-server authorization prompts. Cloudflare and FastMCP already support it.

"Per-user OAuth was a major blocker to deploying agent tool ecosystems in enterprises; centralized, auditable authorization makes MCP deployable at organizational scale."

high

OpenAI's autonomous pipeline found and patched 948 Linux kernel privilege-escalation bugs

OpenAI describes an autonomous pipeline that found, validated, and generated patches for 948 local privilege-escalation vulnerabilities in the Linux kernel — removing a thousand potential root-access paths. The work demonstrates agents performing high-stakes, verifiable security work at scale.

"Agentic security work with machine-checkable outcomes is one of the clearest near-term wins for autonomous agents, and it shifts the economics of vulnerability discovery for critical infrastructure."

Datasette Agent adds side panels: prompt a database app into existence, then edit it in place

Datasette Agent 0.5a0 introduces a panel mode where the agent chat sits beside tables, queries, or apps it built, enabling iterative prompt-driven modification of live database-backed applications. Paired with datasette-apps, agents can create and manage stored queries with user approval for writes.

"It's a well-executed example of harness design — persistent context, approval gates, and editable artifacts — showing how agent UX patterns for building real software are maturing."

Industry & Applications

Reality check: AI agents booked just 4 Uber rides last quarter

Uber disclosed that only four rides and roughly 500 Uber Eats orders were arranged by third-party AI agents in Q3. The disclosure tempers fears of agent-driven disintermediation and shows how early third-party agent integration with consumer platforms remains.

"Agentic commerce is heavily hyped, and this hard production number from a major platform is a valuable ground-truth data point on how little agent-mediated transaction volume actually exists."

Democrats won the Texas governorship, a Senate seat, and the state House, with candidates who campaigned on data center moratoriums. Analysts estimate 13 GW of planned Texas capacity is now exposed, with some projects slipping 12–18 months or leaving the state.

"Compute constraints from political friction could ripple through the entire AI economy — affecting availability, pricing, and the timelines of every lab and agent-dependent product."
