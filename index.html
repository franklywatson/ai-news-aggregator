AI Models & Research

OpenAI's autonomous agents found and patched 948 Linux kernel privilege-escalation bugs

An autonomous OpenAI security pipeline identified 2,308 potential Linux kernel flaws, reproduced 1,724, and generated working exploits and patches for 948 distinct local privilege-escalation vulnerabilities in a single $1.2M run. Researchers estimate the agents found more bugs in a week than human researchers typically discover in a year, with at least 10 techniques considered novel.

"This is a landmark demonstration of long-horizon autonomous agents doing economically significant, verifiable work — and it inverts the security landscape, making vulnerability discovery vastly cheaper than triage and patch review."

Moonshot open-sources Kimi K3.1 Pro, a 2.8T-parameter multimodal agentic model with 1M context

Moonshot released weights for Kimi K3.1 Pro, its most capable 3T-class model, featuring a 1-million-token context window, native multimodality, and strong agentic benchmark results including 75.5% on DeepSWE v1.1. The model activates 104B of 2.8T parameters and ranks #1 among open models on Agent Arena.

"A frontier-scale open-weight model optimized for long-horizon agentic work, released under a relatively permissive license, puts real competitive pressure on closed labs for coding and agent workloads."

OpenAI ships GPT-6 Cyber, a security agent trained to stay inside authorized scope

OpenAI launched GPT-6 Cyber, a cybersecurity-focused model designed to find and fix exploitable vulnerabilities while refusing to attack unauthorized targets. OpenAI says the model went out of bounds in testing less than 1% of the time, down sharply from prior versions.

"The model demonstrates that scope discipline — the key blocker for deploying offensive-capable security agents — is improving, and it's already available in AWS GovCloud for approved government customers."

Developer Tools & Infrastructure

GitHub rebuilds Git storage so thousands of agents can push to one repository at once

GitHub detailed 'Project Rubicon,' a new Git storage architecture that demonstrated 5,000 concurrent agents working on a single repository at 7,200 pushes per second. The design decouples storage from compute, uses a new Ref-CAS replicated log for reference updates, and moves compaction to dedicated background nodes — with agent-focused features like clone-free work and atomic commit APIs on the roadmap.

"This is the clearest signal yet that the industry's core development infrastructure is being re-architected around agent-driven rather than human-driven write patterns — a shift GitHub itself calls 'the point of no return.'"

Perplexity launches 'Teammates,' always-on AI agents for the workplace

Perplexity introduced always-on work agents that take on multiple roles within a workspace, pulling existing projects, skills, and memory from its tools and integrating with Perplexity Computer for on-device agent deployment. The move puts Perplexity in direct competition with OpenAI's and Anthropic's enterprise agent offerings.

"The launch extends the race to own persistent, role-based workspace agents — the emerging interface for enterprise AI — beyond the frontier labs."

Claude can now plug directly into your bank accounts via Plaid

Anthropic launched a Personal Finance feature that connects Claude to users' bank and card accounts through Plaid, letting it answer questions like 'where did my money go this month' with actual transaction data. It's a notable step toward Claude acting as a personal agent with access to highly sensitive financial information.

"Connecting an AI assistant to live financial accounts is a major trust and security test for consumer agents — and a signal of how Anthropic envisions Claude operating as an autonomous personal assistant."

Why a pile of MCP connectors still isn't a context engine

Unblocked argues that MCP connectors give agents access to sources but leave cross-source assembly, contradiction resolution, and unwritten conventions to the most expensive worker — the frontier-model inference loop. Its benchmarks show a context engine can cut task completion time up to 83% and token usage roughly in half compared to raw connector chaining.

"As MCP adoption explodes, this is a sharp articulation of the difference between tool access and genuine context engineering — likely a preview of where agent infrastructure investment flows next."

medium

Open-source tool gives AI agents their own virtual Mac, controlled from the terminal

terminal-mac runs a real macOS guest via Apple's Virtualization framework and exposes it to agents through MCP tools (screenshot, click, type, key) with a bundled skill teaching the observe-act-verify loop. The guest is isolated from the host's apps, sessions, and clipboard, making it a safer sandbox for computer-use agents.

"Isolated, controllable desktop environments are becoming a standard primitive for computer-use agents — this lowers the barrier for testing them on macOS with minimal security exposure."

Consolidation wave in agent tooling: Meta buys Conductor, Factory acquires HumanLayer, OpenAI moves on Pierre

Meta acquired Conductor, whose software lets developers assign pieces of a coding project to multiple AI agents (its cloud service shuts down November 20); Factory is acquiring HumanLayer, a leading agent-control framework; and OpenAI announced plans to acquire Pierre Computer, whose code-navigation tech already powers parts of Codex. Separately, Claude Code's founding product lead Cat Wu left Anthropic for OpenAI.

"Multi-agent orchestration and coding-agent tooling are being consolidated by the big platforms at a rapid clip — independent agent-framework startups are becoming acquisition targets almost as fast as they launch."
