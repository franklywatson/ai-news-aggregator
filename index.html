AI Models & Research

Epoch and METR Release MirrorCode: A Benchmark for Week-Long AI Programming Tasks

Epoch and METR have released MirrorCode, a new benchmark evaluating how well AI systems can re-implement complex software programs purely through CLI access. Claude Opus 4.7 successfully reimplemented 61,000-line programs in 14 hours for $251, a task estimated to take humans 2-17 weeks, demonstrating rapid advancements in long-horizon agentic coding.

"This benchmark reveals that advanced models can now autonomously reverse-engineer and rebuild complex software systems from black-box access, highlighting a critical capability for autonomous software engineering."

Tessl Outlines 'Dark Factories' for Autonomous, Human-Free AI Coding

AI infrastructure startup Tessl has detailed their internal 'Dark Factory' approach, where 95% of shipped code is generated without human review. The company breaks down the discipline of 'harness engineering,' focusing on building robust, self-correcting loops to manage these autonomous software factories.

"The 'Dark Factory' model represents a radical shift in software development pipelines, demonstrating that with proper context and orchestration, autonomous agents can handle enterprise-grade deployments."

New Tool Condenses Technical Books into Context-Efficient Agent Skills

An open-source tool called 'book-to-skill' allows developers to convert dense technical books and documentation into modular 'skills' for agents like Claude Code and GitHub Copilot. By distilling knowledge into on-demand frameworks rather than raw context dumps, it reduces token usage by 24x to 51x.

"This approach to context engineering solves the retrieval vs. reasoning problem, allowing coding agents to efficiently access deep domain knowledge without blowing up context windows."
