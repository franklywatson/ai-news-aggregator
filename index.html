AI Models & Research

Anthropic Mathematician Claims Claude-Helped Proof of the Riemann Hypothesis

Levent Alpöge says he proved the Riemann Hypothesis — and that the method extends to the Generalized and Extended variants — working with Claude, with formalized arguments and no assumptions. He writes that Claude 'far outpaced me near the finish line' of the millennium problem. If verified, it would be one of the most consequential AI-assisted results in mathematics.

"A verified proof of the Riemann Hypothesis would be historic on its own; that Claude was the driving force near the end would mark a watershed for AI-assisted mathematical discovery."

METR's Updated Time-Horizon Plot Shows Exponential Gains — but Judgment Tasks Still Stump Models

METR's revised time-horizon report adds harder and more open-ended tasks and finds task-length capabilities still doubling roughly every four months. But on judgment-heavy tasks like designing AI evaluations or scoring philosophical arguments, frontier models — including Opus 5.5 — fall short of human performance, though they are improving.

"This is the clearest data yet on whether progress on verifiable tasks like coding transfers to the fuzzy judgment tasks required for automating AI R&D itself."

high

Researchers Get a 27B Model to Rewrite Its Own Weights and Get Smarter

A CMU/Stanford team showed an open 27B model diagnosing its own failures and rewriting its own weights through reasoning alone — no gradients, no training — gaining 6.6 accuracy points on unseen problems and repairing a damaged copy of itself to over 80% of original accuracy. The ability emerges only at larger scales; smaller models break themselves.

"Self-rewriting collapses the wall between training and inference and is positioned as a concrete step toward recursive self-improvement."

high

Qwen4 Max Fixes a Real Bug From an Entire Repository in One $0.69 Request

Alibaba's 2.4T-parameter sparse MoE flagship is now on Together AI with a 1M-token context window. In a demonstration, it ingested all 344 files of the Tornado repository plus a bug report in a single request and returned a patch that passes the maintainers' own regression tests — and cites the same code precedent the human fix did.

"It's a vivid demonstration that whole-repository, retrieval-free agent workflows are now practical and cheap, shifting how coding agents should be architected."

Developer Tools & Infrastructure

Nous Research Brings Its Self-Improving Hermes Agent to Teams and Azure

Hermes Agent — the top-ranked public agent on OpenRouter, processing nearly 2 trillion tokens daily — is now available natively in Microsoft Teams, the Microsoft Store, and Azure Container Apps Sandboxes. Its 'Collective Wisdom' feature lets employees convert successful task approaches into shareable, reusable skills, with self-hosted tenant options for strict data-residency needs.

"This pushes self-improving agents from consumer novelty into enterprise workflow infrastructure, and the skill-sharing model turns individual agent know-how into a durable organizational asset."

high

Google Ships A2UI, an Open Protocol for Agents to Answer With Interfaces Instead of Text

Google released A2UI 1.0, an open protocol that lets AI agents respond with a real interactive interface rather than a wall of text. The goal is to standardize how agents present actionable, structured output across applications.

"If adopted, A2UI could become the presentation layer of the agentic web — the counterpart to MCP that defines what users see and interact with when an agent completes a task."

medium

Firecrawl Local: Open-Source Web Scraping for Agents, 37x Faster and Self-Hostable

Firecrawl shipped a local, open-source scraper that runs as a single Rust binary — no database or container — and auto-registers itself as an MCP server in Claude Code, Cursor, Codex, and other agent tools. Scraping, crawling, and PDF/Office parsing all run on-machine, with optional cloud escalation for search and its 550-provider data library.

"Local-first agent data infrastructure reduces token costs and data exposure, and the automatic MCP integration shows how quickly the tooling ecosystem is standardizing."

Herdr Desktop Emerges as a Highly Customizable Agent Orchestrator

Herdr launched a desktop app for running and coordinating multiple coding agents — including Claude Code and Codex — side by side, with extensive customization. It joins a fast-growing field of tools for managing multi-agent workflows on the desktop.

"As developers routinely run multiple agents in parallel, orchestration tooling is becoming the new IDE layer — and whoever wins this surface shapes how agent work gets done."

Microsoft's PyRIT Open-Sources AI Red Teaming With Scanner and GUI

Microsoft's AI Red Team released PyRIT, an open-source toolkit for probing generative AI systems with automated scans, adaptive multi-turn attacks, and human-led testing. It connects to every major model provider and can target complete applications via HTTP, WebSockets, or browser automation.

"As agents become a real attack surface, democratized red-teaming tooling is essential for teams without dedicated security staff to find vulnerabilities before adversaries do."

Industry & Applications

Walmart Opens Its Store to AI Agents as Meta Muse Does the Black Friday Shopping

Walmart is launching its Agent Gateway with Meta's Muse as the first supported agent, letting users delegate deal-finding and purchasing through sandboxed 'Agent Profiles' with spending limits, purchase approvals, and activity logs. The move contrasts sharply with Amazon and eBay, which block AI agents outright, and Walmart says more agents are coming.

"This is one of the first large-scale retail deployments of authorized transactional agents, and the industry split — embracing versus blocking agents — will shape the emerging agentic commerce web."

The Vibe-Hacking Revolution Spreads From Software to Every Gadget You Own

The Verge surveys a booming movement of users pointing Claude Code and Codex at hardware — stripping ads from Android TVs, adding features to cameras and synths, even playing PS2 discs on a PS5. Manufacturers are responding with DRM and legal threats, while ESP32-based open hardware and Meta's Muse Gadgets program offer a sanctioned path forward.

"Agent-driven coding is escaping the terminal and hitting the physical world, forcing hardware makers to choose between locking down devices and embracing a new class of AI-empowered tinkerers."

Together AI Discloses Prompt Leak Caused by an AI Coding Agent Committing a Credential

An AI coding agent committed a credential exposing a private repository of customer prompt samples, which an unauthorized party downloaded and mined for further credentials. Together AI has since made zero data retention the default, added PR credential scanning, and updated its policies governing AI coding agents in development.

"It's a concrete case of agentic development tooling causing a production breach — a warning for every team letting AI agents handle secrets in their repos."
