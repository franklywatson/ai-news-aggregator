AI Models & Research

Tencent Ships Hy4 Preview: 770B-Parameter Open-Weights Model With 1M-Token Context

Tencent released Hy4 Preview, a text-only open-weights LLM with 770B total parameters (49B active) and a 1-million-token context window, up sharply from Hy3's 295B in July. Early testing shows a binary reasoning-effort setting (high/no_think) and competent reasoning traces.

"The long context window and MoE efficiency position Hy4 for long-horizon agentic workloads, and its open weights give developers a credible frontier-class alternative to closed models."

Developer Tools & Infrastructure

LM Studio Launches Bionic, a Full Local-First AI Agent With MCP Support

LM Studio shipped Bionic, its first purpose-built agent for open models, offering document editing, coding-agent tasks, on-device voice transcription, and cloud inference with Zero Data Retention by default. The underlying MLX engine v1.8.5 delivers 2.2x parallel throughput and 82% less memory for long-context agentic workflows via disk-backed KV cache checkpointing.

"Bionic is the most complete out-of-the-box agent experience the open-model ecosystem has produced, and its built-in MCP client support signals that local-first agents are becoming first-class citizens in agentic infrastructure."

Mintlify Introduces Agent Score as Docs Become the Interface for AI Buyers

Mintlify launched a tool to measure whether documentation is 'agent-ready,' as growing numbers of users reach docs through AI agents that trim and reformat content before it hits a model. Poorly structured docs now produce silent failures across agent surfaces nobody can see.

Coding Agents Now Find Exploits From a Mere Rumor of a Bug—Within Minutes

Cambridge professor Anil Madhavapeddy reports that automated watchers probe open-source projects for exploits within roughly ten minutes of a patch being discussed publicly, with coding agents able to locate vulnerabilities from the slightest hint. The rclone maintainer confirms disclosures jumped from ~20 in ten years to over 40 in one month.

"AI-driven vulnerability discovery has collapsed the window between disclosure and exploitation, breaking existing open-source embargo practices and demanding entirely new security coordination processes."

Sony and Warner Chappell Sue Anthropic for Billions Over Training Data

Two major music publishers filed suit against Anthropic and its cofounders Dario Amodei and Benjamin Mann individually, alleging mass torrenting and scraping of copyrighted works including lyrics, with damages potentially reaching several billion dollars. The suit follows Anthropic's recent $1.5 billion settlement with the publishing industry.

"The escalating copyright litigation wave directly threatens the economics of frontier model training and could reshape how companies like Anthropic source data for Claude."

"Pocket represents the consumerization of agentic coding—making agent-built software as easy as posting on social media—while highlighting platform lock-in as the trade-off."
