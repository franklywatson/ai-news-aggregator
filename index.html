Researchers Decrypt Hidden Reasoning Traces from Claude, GPT, and Gemini

A new paper demonstrates that encrypted chain-of-thought blocks returned by frontier model APIs can be replayed into weaker, less-guarded models from the same provider to force plaintext decryption. By scanning public trace repositories, researchers recovered hundreds of API keys and passwords, and also demonstrated a new vector for invisible prompt injection via poisoned reasoning blocks.

"This vulnerability proves that client-side encrypted reasoning is not secure, breaking the confidentiality guarantees that labs rely on to prevent distillation and protect user data."
