AI Models & Research

Z.ai's GLM-5.3 Gains Come Entirely From Post-Training — and It's Learning to Exploit Vulnerabilities

GLM-5.3 shares its base model with GLM-5.2 but jumps from 4.6 to 28.3 on Terminal-Bench 3.0 via RL on synthesized long-horizon environments. More striking, its cybersecurity capabilities scaled unexpectedly fast, setting a CyberGym record and surfacing 2,436 real vulnerabilities across 269 projects through deployments with Chinese security teams.

"It's a data point for the 'post-training scaling law' over parameter count, and the emergent exploitation capability — growing fastest exactly where the open frontier is furthest behind — lands amid ongoing rogue-agent security concerns."

Z.ai CEO Declares the Death of Parameter Count as a Scaling Metric

Jie Tang argues parameter counts are meaningless without data volume, compute allocation, and deployment context, and identifies five scaling knobs including MoE sparsity. He frames advanced agentic skills as long causal-chain reasoning that emerges from post-training RL, not memorization capacity.

"Signals an industry-wide shift in how model progress is measured and marketed — from pretraining scale to environment and recipe quality."

Frontier AI Out-Persuades Expert Humans — and Is 3x Better at Real Fundraising

In four preregistered experiments with nearly 19,000 conversations, AI systems reliably beat tournament winners, professional canvassers, and world-champion debaters at persuasion, even when experts were coached and cash-incentivized. AI was nearly 3x more effective than professionals at raising real donations.

"The advantage stems from information throughput rather than cleverness — with direct implications for political communication, scam defense, and the integrity of human-AI interaction."

Stanford Applies Statistical Mechanics to Predict How 10,000 Agent Communities Reach Consensus or Polarize

A study of over 10,000 LLM agent communities shows collective dynamics collapse into three regimes — indifference, polarization, consensus — that a statistical-mechanics model can predict from initial opinions alone. Communities operate below 'critical social temperature,' with truth-holding agents exerting the strongest pull.

"As multi-agent systems move into production, predictive laws for their collective behavior become essential for orchestration design and alignment."

Training-Free 'Recirculation' Cuts Gemma3 Perplexity 23% and Lifts Math Accuracy 21%

Researchers introduce a recurrence-based inference-time enhancement that lets frozen transformers track belief states, cutting Gemma3 perplexity by 23% and boosting GSM8k accuracy by 21% with no retraining and no added generation latency.

"Offers a cheap architectural upgrade path for existing models and hints at architecture evolution guided by trained networks themselves."

TrueFoundry Open-Sources TrueForge, an MIT Harness That Undercuts Claude Managed Agents by 75%

TrueForge bundles tool orchestration via MCP, sandboxing, subagents, human approvals, and context management in a self-hostable harness. On a 14-task enterprise benchmark it matched Claude Managed Agents on Opus 4.8 with ~30% fewer tokens, and routing to GLM-5.2 cut costs ~75% at equal accuracy.

"Makes the cost argument for harness-level engineering explicit: the session/context/tools layer, not the model, is becoming the main lever for both differentiation and savings."

Cursor's Cloud Agents Now Wake Themselves: Event Subscriptions, Persistent Goals, and VM-Isolated Subagents

Cursor agents can now subscribe to PRs, Slack threads, and schedules, waking autonomously to drive work to completion — including fixing CI on their own PRs. Subagents get isolated virtual machines, and a new /goal command lets agents pursue long-lived objectives across sessions.

"Moves coding agents decisively from on-demand tools toward always-on autonomous systems that operate without per-loop human intervention — with all the guardrail questions that entails."

BrowserCode Turns Browser Agents Into Coders via Raw Chrome DevTools Protocol

BrowserCode reframes web automation as a coding problem: the agent writes JavaScript that drives Chrome directly through CDP, persisting reusable scripts as it goes. It claims to outperform every browser agent tested, with Claude Opus 4.8 as the top-performing model.

"A clean demonstration that code generation beats abstraction layers for browser control — a meaningful design pattern for the broader agent-harness space."
