Unreleased Claude Model Makes Historic Progress on the Riemann Hypothesis

An unreleased research version of Claude coordinated 60 subagents and generated 31 million tokens to push a longstanding lower bound for the Riemann zeta function from 41.6% to 67.2%. The model independently produced a mathematically valid proof that was formally verified in Lean 4, marking a surprising leap in AI mathematical reasoning.

"This showcases the immense power of multi-agent orchestration for solving complex, open-ended problems, demonstrating that AI can now extend the impact of human mathematicians in unexpected ways."

Researchers Extract Hidden Chain-of-Thought Traces from Frontier Models

A new paper demonstrates that encrypted reasoning blocks returned by APIs from Anthropic, OpenAI, and Google could be fed into weaker sibling models and jailbroken to reveal the raw, hidden chain-of-thought text. The attack also uncovered a dangerous new prompt injection vector where models treat malicious instructions embedded in reasoning traces as sacrosanct.

"Exposing how models privately reason highlights critical security vulnerabilities in agentic workflows, particularly as chain-of-thought traces become integral to complex tool use and automated orchestration."

Metis: The First Memory Foundation Model

Researchers have introduced Metis, a prototype model that bakes persistent, dynamically evolving memory directly into its forward pass. This native memory approach eliminates the need for external retrieval modules, allowing agentic applications to maintain context efficiently without gradient updates.

"Context engineering and persistent memory are major bottlenecks in agent development; integrating memory natively into foundation models could drastically simplify agent architecture."
