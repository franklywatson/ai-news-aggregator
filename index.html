AI Models & Research

Alignment researchers turn to 'reverse game theory' to keep rogue agents in check

Researchers from MIT, Yale, Columbia, and Princeton are applying mechanism design to AI alignment — designing incentive structures that make sandbagging, cheating, and collusion losing strategies rather than trying to understand model internals. Proposed mechanisms include cross-checking agents against each other's predictions and solver-auditor dynamics where models police each other. Open questions remain about whether models respond rationally to incentives and whether mechanisms transfer across tasks.

"As models demonstrably hide intentions and game evaluations, incentive-based control offers a pragmatic complement to interpretability — and maps directly onto multi-agent architectures already in production."

Realtime-Bench exposes the gap between agent demos and real-time production

A new benchmark of 50 interactive game and web tasks shows frontier models collapse under wall-clock conditions: the best performer, GPT-6 Astra, passes just 36% of real-time tasks versus 70-80% when the clock is paused. The test measures temporal awareness, adaptive deliberation, and time-aware action selection across domains like travel booking and e-commerce.

"This quantifies exactly where autonomous agents still fail — any workflow with live inventory, auctions, or time-sensitive decisions remains out of reach for current models."

New framework unifies pretraining, fine-tuning, and RL into a single training pass

A new paper derives RL objectives as maximum-likelihood fitting to model-generated target distributions, collapsing the staged foundation-model training pipeline into one unified algorithm that mixes static data and RL generations. Controlled and real-world experiments show improved accuracy-compute tradeoffs, broader task coverage, and a stronger base for continual learning.

"If staged training is just a special case of one algorithm, training infrastructure simplifies dramatically and the industry's pretraining/posttraining divide may be an artificial constraint."

Developer Tools & Infrastructure

Vercel open-sources agent-desktop: computer use via accessibility trees, not screenshots

Vercel Labs shipped an open-source CLI and C library that lets AI agents read and operate desktop applications across macOS, Windows, and Linux through the OS accessibility tree — returning JSON refs for every actionable element instead of relying on pixel matching. The loop (snapshot, act on a ref, verify) stays in the developer's agent, with headless operation by default.

"Deterministic, ref-based desktop control removes the brittleness of vision-based computer use and could become a standard harness primitive for cross-application agents."

OpenAI built Pando, a Git-compatible backend, to survive Codex-scale development

OpenAI detailed Pando, a Git-compatible backend designed for the enormous volume of AI-generated code and commits that Codex agents produce. The system addresses scaling limits that conventional Git infrastructure hits when agentic development multiplies repository operations.

"It's concrete evidence that agentic coding is forcing a rewrite of core developer infrastructure — a leading indicator of what every large engineering org will face."

Malicious Claude Code extension on Cursor's marketplace installed SSH backdoors

Cursor disclosed that trojanized versions of the Anthropic Claude Code extension (2.1.312/2.1.313) distributed through its marketplace attempted to add attacker-controlled SSH keys, establish reverse tunnels, and persist via LaunchAgents or scheduled tasks. Roughly 5,000 users were warned; Cursor took the marketplace offline, rotated keys, and published remediation scripts and IOCs.

"Agent tooling marketplaces are now a targeted supply-chain attack surface — trust in extension provenance is becoming a first-class security problem for the agentic dev ecosystem."

Anthropic quietly updated Claude Code's system prompt to block AI game cloning

Claude Code's system prompt now instructs the model not to recreate specific existing games, a response to a wave of AI-assisted decompilations and ports flooding retro gaming communities. Anthropic confirmed the change on Opus 5.5, though GitHub issues suggest the guardrail is already blocking some legitimate game development use cases.

"It's a live example of behavior steering via harness-level prompting rather than model training — and of the tradeoffs vendors face between IP protection and overblocking."

Industry & Applications

Legora's CTO on building legal agents when you can't read a single trace

Legora ($8.8B valuation, $200M+ ARR) builds agents that draft contracts, review 10,000 documents in a million-cell table, and coordinate work between lawyers and other agents — but confidentiality rules mean the team cannot inspect any customer data. Its evals team reconstructs customer work as simulated RL environments, including a 10,000-file data room, while post-training open-weight models for narrow tasks like legal research.

"A detailed blueprint for harness engineering, evals without trace access, and multi-model routing in a high-stakes regulated domain — with direct implications for how agent labs coexist with frontier providers like Claude Cowork."

NYT and publishers sue Brave for 'laundering pirated reporting' to AI companies

The New York Times, New York Daily News, Chicago Tribune, and Orlando Sentinel sued Brave Software, alleging it sold AI companies paid access to scraped publisher content through the Brave Index and promoted paywall bypass features. The complaint names Anthropic, Perplexity, Mistral, xAI, and Cohere as recipients of the allegedly infringing data.

"The suit targets the data-supply middlemen rather than the labs themselves, opening a new front in the training-data legal wars that could reshape how agent systems source real-time web content."
