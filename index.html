AI Models & Research

Nex-AGI Open-Sources Agentic Model Family Built for Computer Use and Self-Correction

Nex-AGI released Nex-N2.5 in mini, Pro, and Max sizes, with the flagship Max built on a 1.6-trillion-parameter MoE foundation. The models are specifically trained for long-horizon agentic tasks — browsing, computer use, and visually-grounded self-correction — and all weights are open source.

"Vision-first agentic post-training at trillion-parameter scale, released as open weights, lowers the barrier for developers building computer-use agents."

RadixArk Open-Sources Miles, a Production-Ready RL System for Frontier-Scale Agentic Training

Miles v0.1 is a full-stack post-training system combining SGLang rollout engines, Megatron-LM/FSDP trainers, and multiple weight-sync transports, supporting full-parameter and LoRA RL. Its case study demonstrates fully asynchronous agentic RL on a 744B-parameter GLM-5.2 model over terminal-use coding tasks.

"Frontier-scale agentic RL has been largely locked inside big labs; open-sourcing the training loop could accelerate the entire agent ecosystem."

Claude Code creator Boris Cherny details Anthropic's internal guardrails for agent-written production code: extensive lint rules, tests, Claude-driven end-to-end tests, daily fuzzers, and automated code and security reviews. Without these, he warns, agent-written code becomes unmaintainable.

"Firsthand guidance from Anthropic on harness engineering for agentic coding — validation infrastructure, not prompting, is what makes agent code shippable."

GPT-6 Astra Ran a 27-Minute Geospatial Task — and Then Lost Its Own Work

Simon Willison describes ChatGPT Work autonomously generating running routes from OpenStreetMap data over 27 minutes, producing visualizations and GPX files. But context compaction destroyed the record of the code it ran, leading him to argue that systems using compaction must preserve and expose pre-compaction history.

"A concrete case study in context engineering failure modes: without durable, inspectable memory, long-horizon agents lose auditability — a transparency anti-feature becoming common in production agents."
