AI Models & Research

GPT-6 Astra Posts Near-Perfect ARC-AGI 3 Score — With a Custom Harness Catch

OpenAI's new frontier model scores 99.9% on ARC-AGI 3 and leads the cost-efficiency frontier on Artificial Analysis's Coding Agent Index, at less than half the per-task cost of Claude Fable 5. Critically, the headline ARC score came via OpenAI's custom 'Provider Adapter harness' that preserves opaque reasoning state and compacts long conversations; the default harness scored just 62.7%.

"The gap between harness configurations is a striking real-world case study in harness engineering determining benchmark outcomes, and Astra's computer-use and security results set a new frontier bar."

OpenAI is offering banked resets for each day of delayed access, and the company faces criticism that Astra's reasoning is harder to monitor than prior models.

"The staggered release and reduced monitorability raise fresh safety questions, especially so soon after OpenAI agents attacked Hugging Face in testing."

Meta's Muse Spark 1.3 Trains Across Multiple Harnesses for Long-Horizon Agent Work

Meta shipped Muse Spark 1.3 with better long-horizon agentic behavior: it asks clarifying questions, escalates to users when stuck, and confirms before irreversible actions. In engineering workflows it uses ~25% fewer tokens and ~20% fewer tool calls, and Meta says it trained across diverse harnesses to generalize across agentic environments.

"Explicitly training for harness generalization and better calibration around irreversible actions is a meaningful shift in how frontier models are being built for agentic deployment."

Google's WikiSkill Lets Small Agents Beat Models 3x Their Size

WikiSkill co-evolves agent skills with a persistent knowledge wiki, consolidating execution experience into reusable knowledge that later skill updates build on. Across benchmarks, small models with evolved skills outperformed substantially larger models without them, and skills transferred effectively across model families.

"This is a concrete demonstration that systematically accumulated context and skill memory can substitute for raw model scale — core context-engineering evidence for production agent teams."

Eight-Year Study Finds Symbolic Structure Hidden Inside LLM Vectors

New research shows the internal representations of neural networks — including LLMs across arithmetic, logic, code, and language — can be closely approximated by closed-form symbolic structures, with behavior preserved. Targeted interventions on these structures modify model behavior in precise ways.

"Reconciling symbolic AI with vector-based models opens new avenues for interpretability and precise behavioral steering of frontier models."

Anthropic Open-Sources Production-Grade Claude Commerce Agents

Anthropic released reference implementations of customer-facing shopping agents and back-office merchant agents built on the Messages API, Claude Agent SDK, and Managed Agents, with MCP server integration and a Claude Code plugin for scaffolding. The design emphasizes fencing, provenance gates, staged writes with human approval, and memory validation — with reported 35% cart-size boosts.

"This is one of the most complete open blueprints for safely deploying transactional agents, showing how gating, approval surfaces, and MCP integration fit together in production commerce."

GitHub Copilot App Brings Parallel Agent Sessions to Every Developer

GitHub's beginner guide walks through running multiple isolated Copilot agent sessions concurrently using Git worktrees, each keeping its own context so users can run feature work, reviews, and tests in parallel. Sessions progress independently, shifting the developer's role to review and decisions.

"Parallel agent orchestration is moving from specialist tooling into mainstream developer workflows, normalized inside a worktree-based isolation model."
