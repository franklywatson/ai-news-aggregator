Anthropic Used Claude to Solve a 40-Year-Old Biology Mystery in Under Four Months

Anthropic's biology lab used Claude at every step — literature search, DNA construct design, purification, and cryo-EM analysis in a multi-agent harness — to map the first vault particle structure found in prokaryotes. A purification that normally takes three days took 90 minutes, and a structural model that takes weeks was ready in 34 hours.

"A concrete demonstration that AI-driven autonomous science is compressing months of expert wet-lab and structural biology work into days, by a team with little prior domain experience."

Latent Sparse Attention Delivers 9x Faster First Tokens for Drowning Coding Agents

Prefrontal AI's LSA clusters attention keys in a learned latent space so each query scores clusters instead of every key, achieving up to 72x faster attention than full attention at long context while preserving accuracy. It ships as an SGLang plugin and runs on Qwen3.8-27B and GLM-5.3-Flash out of the box.

"Directly targets the context bloat that agentic workloads create, continuing the inference-first optimization wave that is making million-token agent sessions practical."

Microsoft's TokenEconomizer Cuts Coding Agent Token Waste

Microsoft Research and UC Berkeley released TokenEconomizer, a free open-source plugin that reduces token consumption in AI coding agents like Claude Code by trimming redundant context, without requiring model changes.

"Token overhead is the dominant cost driver in agent harnesses; a drop-in efficiency layer addresses the harness-bloat problem highlighted by recent research showing heavyweight harnesses can quintuple costs."

"Slop Creep": AI Agents Quietly Bloat Codebases

A developer coins the term "slop creep" to describe how coding agents pick at insignificant details, over-cover edge cases, and miss existing functionality—gradually making codebases more complex. Often, when questioned, the agent's own justification reveals the work wasn't needed.

"As AI coding agents become default tools, this failure mode is a real maintenance risk. It argues for actively reviewing agent decisions rather than blindly accepting generated code."
