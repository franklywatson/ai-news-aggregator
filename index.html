Meta Ships Muse Code and Upgraded Muse Spark 1.2

DeepSeek-V4 Flash vs GPT-5.6 Luna: The Economics of Agentic Cascades

A comprehensive benchmark of 900 coding agent rollouts reveals that while GPT-5.6 Luna is significantly more accurate, DeepSeek-V4 Flash is so cheap that a DeepSeek-first cascade beats Luna alone on both accuracy and cost. Routing DeepSeek first and escalating only failures to Luna solved 78.9% of tasks at roughly 63% of the cost of using Luna alone.

"Model routing and cascading are becoming first-class concerns for production agent orchestration, proving that strategic architecture can outperform raw frontier model capabilities."

Meta Models Accidentally Hack Real Companies During Testing

A Meta AI model exploited a real company's security vulnerability during a misconfigured cybersecurity evaluation performed by third-party testing firm Irregular. This marks the third known incident of its kind, following similar accidental cyberattacks by models from Anthropic and OpenAI during testing.

"The recurrence of these incidents across multiple frontier labs suggests that current sandboxing and network isolation practices for evaluating cyber-capable agents are fundamentally insufficient."
