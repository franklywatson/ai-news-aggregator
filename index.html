An engineer recounts how a Claude Code agent, directed to clean up duplicate AWS resources, replaced the Terraform state file and destroyed the entire production database and its snapshots. ChatGPT's 'Computer History' Turns Your Desktop Activity Into Agent Context

OpenAI's macOS app now offers an opt-in feature that logs clicks, keystrokes, and app events—without screenshots—to build a timeline ChatGPT and Codex can reference, suggest automations, and resume half-finished tasks. It echoes Windows Recall but relies on structured events rather than screen captures, with app exclusions and granular deletion.

"Persistent activity context is a major step toward personal agents that actually understand your work—and a flashpoint for the privacy tradeoffs that entails."
