SPADE: Models That Generate Their Own Training Environments via Self-Play

A multi-university team built SPADE, a framework where an LLM alternates between writing executable training environments and solving them, using hint-based regret to co-evolve environment difficulty with agent capability. The technique improved benchmark performance across Qwen3 backbones and works for both game and tool-use agentic tasks. It's a practical step toward automated, open-ended synthetic data generation for agents.

"Environment generation has become a bottleneck for agentic RL; automating it could dramatically lower the cost of training capable tool-using agents."

"Funding for safety work on models anyone can fine-tune is scarce; this directly targets the hardest open problem in agentic AI deployment."

Developer Tools & Infrastructure

Anthropic Ships Passwordless Enterprise Auth for Claude MCP Connectors

Claude Team and Enterprise customers can now configure Enterprise Managed Auth, which lets Claude silently exchange signed identity assertions from a company's IdP for MCP connector access tokens—no OAuth redirects or consent screens for users. The feature supports lazy authentication and Okta Cross App Access, removing a major deployment friction point for enterprise MCP adoption. Identity provider setup is handled entirely by customer administrators.

"Authentication has been one of the biggest blockers to rolling out MCP connectors in enterprises; silent SSO-style auth could unlock large-scale connector deployments."

Claude Code Remote Control Adds Phone-to-Machine Sessions and Push Notifications

Claude Code's Remote Control now supports starting sessions from your phone, faster automatic reconnects after network drops, mobile push notifications when long tasks finish or permission approvals are needed, and a beta Trusted Devices feature with biometric step-up for Team and Enterprise. Subagent and workflow state stays synchronized across terminal, browser, and mobile. Execution and filesystem access remain on the local machine.

"This turns long-running agentic coding sessions into supervise-from-anywhere workflows, a meaningful shift in how developers orchestrate autonomous agents."

GitHub Shares Its Playbook for Evaluating LLMs Before Production

GitHub's applied science team detailed how they evaluated an LLM system for reducing false positives in secret scanning, achieving a 95% false-positive reduction while keeping recall inside safety guardrails. The post outlines practices including treating offline evaluation like integration testing, changing one variable at a time, and using LLM-as-judge for triage rather than ground truth. It's a rare detailed look at production-grade LLM evaluation discipline.

"As agents move from demos to production, rigorous evaluation methodology is the difference between a working system and a liability—this is one of the most actionable write-ups yet."

Pi Coding Agent Cuts Context Costs 88% by Spilling Tool Output to Disk

The Pi coding agent implements a disk-spill memory strategy that moves bulky tool outputs out of the context window and retrieves them on demand, reportedly cutting context costs by 88%. It's a concrete example of context engineering—managing what fills a model's window—becoming as important as model choice. The approach is particularly relevant as expensive flagship models make token efficiency a first-class concern.

"With frontier model prices climbing, harness-level optimizations like this can determine whether agentic coding is economically viable at scale."
