Developer Tools & Infrastructure

Anthropic opens private beta for self-hosted Claude agents inside your own cloud

Self-hosted Claude Managed Agents runs the full agent control plane — harness, sandboxes, credentials, and session history — inside a customer's own environment, with model requests routed to Anthropic, Bedrock, Vertex, or a custom gateway. The design splits the 'brain' (harness) from the 'hands' (sandbox), keeps credentials out via vaults, and exports full agent audit trails over OpenTelemetry.

"Enterprises want unattended agents with deep internal access without shipping code or secrets to a vendor's cloud. This directly targets the same self-hosted-agent-infrastructure shift Cursor recently enabled, and makes Anthropic a credible platform for production agent deployments in regulated environments."

OpenAI launched ChatGPT Wallet for Pro subscribers in the US, allowing agents in ChatGPT Work, Codex, and Dots to make purchases using existing American Express, Chase, Mastercard, and Visa cards with user approval flows and standard card protections. New paper argues agents don't need long context — frequent compaction loses almost nothing

The study shows that on frontier open-weight models, later tokens can cost up to 7x more to generate, yet maintaining short contexts via frequent compaction sacrifices little to no accuracy on long-horizon tasks. Models even hold up on long-horizon software engineering when taking at most one action per context, leading the authors to propose 'semantic state space models' and question the need for long-context LLMs entirely.

"This is a direct challenge to the long-context arms race and a boost for context-engineering approaches: if compaction is nearly free in accuracy, agent harnesses can be dramatically cheaper and faster. It aligns with emerging evidence that heavyweight memory and context machinery often adds cost without quality."

NVIDIA open-sources SkillEvaluator for scoring and securing agent skills

SkillEvaluator is an open-source CLI that validates, deduplicates, and live-evaluates AI agent skills across three tiers — static quality checks, embedding-based overlap detection, and sandboxed agent runs measuring whether a skill actually helps. It integrates with CI pipelines and drops directly into Claude Code, Codex, or other agents via the Agent Skills specification.

"As skills become the packaging unit for agent capabilities, tooling to test their quality and security is the missing QA layer for the agent ecosystem. The Claude Code/Codex integration signals convergence on a shared skill format across vendors."

Anthropic research: adding clean data can triple the power of poisoned training sets

A new paper documents 'homeopathic learning,' where poisoned fine-tuning data that has no effect on its own creates a hidden backdoor — including model misalignment — once clean, contrasting data is added. The trigger-and-regularization mechanism means identical poisoned examples can be harmless in one training set and dangerous in another.

"This exposes a serious limitation of safety methods that audit training data in isolation. As fine-tuning and post-training proliferate, data-supply-chain attacks become far harder to detect than previously assumed."

NYU method matches full fine-tuning by deleting just 0.1% of weights

NeurIPS-published 'Deletion Tuning' learns which pretrained LLM weights to remove — rather than updating them — and matches full GRPO/SFT fine-tuning performance on math, reasoning, and tool-use benchmarks. The team released trained masks for Llama and Qwen models that can be applied to base weights to reproduce post-trained models.

"Post-training via pure deletion is both theoretically striking and practically appealing: masks are tiny, composable, and auditable. It suggests post-training effects may live in a remarkably sparse subset of parameters."
