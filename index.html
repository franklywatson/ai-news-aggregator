Claude Fable 5.2 Coordinates 1,000 Agents to Formalize Fermat's Last Theorem in 30 Hours

Anthropic's Fable 5.2 and Mythos 5.2 ship 30% faster outputs at lower prices, topping Opus 5.5 on agentic coding and science benchmarks. Qwen's DSpine Speculative Decoding Hits 125 tok/s on a Single Consumer GPU

Community GGUF conversions of Tencent's DSpine draft model for Qwen3.8-27B achieve 3.2x speedups on a single RTX 3090 — up to 129 tok/s on code — by drafting 16 tokens in parallel from target-model hidden states. Community benchmarks across AMD, Intel, and DGX hardware show consistent gains, strongest on code and tool-call generation.

"Inference-first speculative decoding makes frontier-class local agent speeds accessible on consumer hardware, with the biggest wins exactly where agents spend tokens: code and tool calls."
