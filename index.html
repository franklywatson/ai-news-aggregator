Developer Tools & Infrastructure

Inside Anthropic's Managed Agents: separating the agent's 'brain' from its 'hands'

Anthropic engineering leaders explained the architecture behind Claude Managed Agents: a durable harness that persists while ephemeral sandboxes execute code, with credentials held in a separate vault and injected via proxy so the agent never touches secrets. The team also detailed anti-distillation measures, a full Rust rewrite of the Messages API cutting CPU ~40-50%, and plans to expose multi-agent strategy primitives like 'Dreaming.'

"This is one of the clearest public blueprints for secure, scalable agent runtime design — harness/sandbox separation, credential isolation, and egress controls are becoming the reference architecture for agent infrastructure."

high

Harness engineering gets a definition: what's actually new around the model

A new discussion breaks down harness engineering — the tools, context, guardrails, and telemetry layer surrounding models — and separates genuine innovation from rebranded prompt engineering. It comes as managed harness offerings (like Claude Managed Agents) let developers skip building this layer entirely.

"As models commoditize, the harness layer is where developers differentiate; clarity on what belongs there will shape how teams build agent products."

NVIDIA open-sources Auto Ontology, a semantic context layer for agents over MCP

NVIDIA released an Apache 2.0 library that builds enterprise ontologies from metadata, reconciles conflicting metric definitions across systems, and validates agent-generated queries against certified lineage — exposed to any agent harness via MCP, CLI, or API. It targets the reliability problem of agentic text-to-SQL returning plausible but wrong numbers.

"Trusted semantic grounding is a key missing piece for enterprise analytics agents, and serving it over MCP makes it pluggable into Claude, Cursor, and other harnesses."
