AI Models & Research

Self-Harness: A New Paradigm for Self-Improving Agent Scaffolding

Researchers have introduced 'Self-Harness,' a framework that allows LLM-based agents to autonomously identify their own weaknesses and rewrite their operating scaffolding to improve performance. In testing across multiple models on Terminal-Bench-2.0, this iterative loop significantly boosted held-out pass rates without requiring human engineer intervention.

"Manual harness engineering is brittle and scales poorly as models evolve rapidly. This research represents a major step toward agentic systems that can autonomously adapt and optimize their own context and tool usage for better reliability."

New 35B Parameter Model Outperforms Trillion-Parameter Giants on Agentic Tasks

A new 35B Mixture-of-Experts agentic model called Agents-A1 achieves performance comparable to 1T-parameter models by scaling the agent horizon rather than raw parameters. The model utilizes a multi-teacher domain-routed distillation recipe to unify six heterogeneous domains into a single deployable student model.

"This proves that specialized, smaller models trained on long-horizon agentic trajectories can match frontier models on complex tasks, offering a much more cost-effective path for deploying advanced autonomous agents."

Fable 5 Writes Record-Breaking Kernel, Hinting at Automated AI R&D

Anthropic's Claude Fable 5 has written the fastest megakernel ever submitted to KernelBench-Mega, achieving an 18.71x speedup by solving the problem with a single cooperative kernel launch per decoded token. This milestone demonstrates AI's growing ability to fundamental AI research tasks like kernel design, a key component for potential recursive self-improvement.

"As AI systems become capable of autonomously designing and optimizing the foundational building blocks of AI compute, it signals a shift toward AI actively accelerating its own underlying research and development."

Developer Tools & Infrastructure

Claude Fable 5 Successfully Drives Major Open-Source Release Pipeline

Simon Willison detailed how he used Claude Fable 5 to handle the bulk of the sqlite-utils 4.0RC2 release, involving 37 prompts and 34 commits to fix complex transaction-handling bugs. Willison cross-verified the agent's work using GPT-5.5 and highlighted the effectiveness of letting agents use their own judgement for testing and task delegation.

"This real-world case study showcases the maturation of agentic coding tools, demonstrating how orchestrating multiple models via Claude Code can reliably handle complex, multi-file software engineering tasks at scale."

Better Models, Worse Tools: Claude Opus 4.8 Struggles with Third-Party Harnesses

Developer Armin Ronacher reports that newer Anthropic models like Opus 4.8 and Sonnet 5 are increasingly inventing made-up keys and malformed arguments when using custom coding tools outside of Claude Code. This regression appears linked to RL training specifically optimizing models for Anthropic's native edit tools, degrading performance for third-party harnesses like Pi.

"As frontier models become heavily optimized for specific proprietary harnesses, developers building custom agent scaffolding may face new challenges with tool schema adherence and reliability."

Maximizing Claude Code: Delegating Tasks to Cheaper Subagents

Developers are finding that giving Claude Fable 5 the autonomy to use its own judgement yields better results than strict instructions, particularly when delegating coding tasks. A new tip from the Claude Code team suggests instructing Fable to automatically spawn subagents using lower-power models for mechanical implementation work.

"Effective context engineering and dynamic model delegation are becoming critical skills for managing costs and optimizing complex, multi-step agentic workflows in tools like Claude Code."

GitHub Launches Spec-Kit to Structure Agentic Coding Before Implementation

GitHub has released spec-kit, an open-source tool designed to help developers define and structure project specifications before an AI coding agent begins writing code. This proactive approach aims to improve the reliability of AI-generated code by ensuring the agentic system has a clear, structured plan to follow.

"Context engineering and upfront specification are proving essential for guiding autonomous coding agents effectively and preventing hallucinations in production software engineering."

Microsoft Open-Sources SkillOpt for AI Agent Skill Optimization

Microsoft has open-sourced SkillOpt, a new framework designed to act as a 'cheat code' for dynamically optimizing and managing the skills available to AI agents. The tool allows developers to more efficiently route tasks and manage the capabilities of autonomous systems.

"As multi-agent systems grow in complexity, dynamic skill management and orchestration will be crucial for maintaining efficiency and ensuring agents can successfully execute specialized tasks."

AI Agents Trigger npm Supply Chain Security Concerns via npx Auto-Install

AI coding agents frequently run `npx` commands like `npx tsc` without local packages installed, causing npm to auto-install packages—potentially untrusted ones—on the fly. This highlights a real supply chain attack vector as agents blindly execute commands that pull in arbitrary packages.

"As AI agents become ubiquitous in development workflows, their tendency to run commands without human review creates serious supply chain risks that the npm ecosystem is not currently designed to mitigate."
