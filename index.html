AI Models & Research

Meta's Muse Spark Open is the most capable US open-weight model — and it runs on two Mac Studios

Meta released Muse Spark Open, an 816B-parameter model (42B active) with a 1M-token context window, built for agentic coding, computer use, and multimodal browsing. In a surprise partnership, Apple worked with Meta to make it run locally on two M5 Ultra Mac Studios via the MLX framework. It is available from Together AI starting at $1.25 per 1M input tokens.

"A frontier-class open-weight model with long-horizon agentic capabilities and 1M-token context, runnable on commodity desktop hardware, dramatically lowers the barrier to self-hosted agent infrastructure."

Fork-and-flush: simple context reset boosts research agents 66% by escaping 'idea basins'

Researchers show that autonomous research agents get trapped in localized regions of solution space, plateauing at different scores across independent runs. A simple intervention — forking the agent into parallel trajectories with fresh chat contexts and continuing from the best — beat single-run and best-of-N baselines by 66% and 44% on 13 long-horizon tasks.

"This is a concrete, cheap context-engineering technique for long-running agents, evidence that managing context decay matters as much as model capability for multi-day autonomous work."

Agent memory isn't storage, it's search: one Postgres table beats complex RAG pipelines

A TigerData team put raw conversation turns in a single Postgres table exposed via three MCP tools and beat the best published LoCoMo memory system (F1 0.665 vs 0.613), with no fact extraction, summarization, or graph-building. The post also shows LoCoMo judge scores swing 18 points based purely on prompt configuration, arguing the leaderboard is saturated with benchmark noise.

"A strong data point that models with well-designed tool interfaces can replace heavy ingestion pipelines — and a damning audit of how memory benchmarks are being scored."

OpenAI brings GPT-Rosalind to academic life-sciences labs with sponsored access plan

OpenAI launched the Rosalind Academic Plan, offering eligible academic labs sponsored access to GPT-Rosalind plus supporting tools for life-sciences research. The move extends OpenAI's science-focused model from industry partnerships into academia.

"Frontier AI-driven scientific discovery is being institutionalized; subsidized academic access could accelerate autonomous-research deployments in genomics and drug discovery."

Developer Tools & Infrastructure

GitHub: the next developer interface is ambient intelligence across voice, agents, and physical controls

GitHub argues software development is shifting from operating tools to expressing intent, with a three-layer architecture: modality (intent capture), harness (planning and action via MCP and skills), and a control plane for inspection and approval. The company announced a Logitech MX Keypad integration that maps physical keys to Copilot agent actions like resuming sessions and triggering multi-step workflows.

"One of the clearest articulations yet of harness engineering as a product discipline — and a sign that agentic coding interfaces are expanding beyond keyboard and terminal into physical and ambient controls."

Claude Code desktop app now runs multiple coding sessions side by side

Claude Code's desktop app supports parallel sessions across local, cloud, SSH, and WSL environments, with permission modes ranging from manual approval to a classifier-based Auto mode. The Cowork tab runs an autonomous background agent that works on tasks independently while the developer does other work.

"Parallel agent sessions plus an always-on background cowork agent mark Claude Code's evolution from a single-session assistant toward a multi-agent orchestration workbench."

Modal hits $1B ARR and a $16B valuation on the back of agent sandboxes

Modal raised a $750M Series D at a $15.75B valuation after crossing $1B in annualized revenue, with usage up 15x year over year. Its sandbox product — nearly 3 billion sandboxes spun up, scaling to a million concurrent — has become a $300M run-rate business powering background agents, RL training, and vibecoding platforms.

"Agent execution environments have become a decacorn-scale infrastructure category; secure, ephemeral sandboxes are now the load-bearing layer for deployed autonomous agents."

DigUp: open-source local semantic search for photos, audio, and code using EmbeddingGemma 2

DigUp is a free, open-source desktop tool that indexes local files — images, PDFs, audio, video, and code — with Google's 740M-parameter multimodal EmbeddingGemma 2 model and lets users search by natural-language description, jumping to the exact page or timestamp. Everything runs locally with no telemetry.

"A glimpse of on-device multimodal retrieval as a default capability — and a building block for privacy-preserving personal agent memory."

Bluesky's Attie expands from AI feeds to building shareable social apps and games

Bluesky's Attie AI tool now lets users create 'small' social apps — games, polls, dashboards — that run on the AT Protocol and can be shared as standalone websites. Users can bring their own model or choose open-weight options, with distribution through Bluesky's existing network.

"Vibe-coding is being productized for non-developers with built-in social distribution, a distinctly different distribution bet than standalone app builders."

ChatGPT can now read and control your Chrome tabs

OpenAI upgraded its Chrome extension so ChatGPT can view and act on users' open browser tabs — comparing products, filling forms, sending messages, and organizing tabs — when tagged in the web or desktop app. The move effectively ports the discontinued Atlas browser's agent capabilities into the browser most people already use.

"Browser control is the most concrete path to general-purpose consumer agents, and OpenAI just made it available to Chrome's billions of users rather than requiring a custom browser."

Anthropic revenue hits $16.8B in Q3, up nearly 50%, as IPO nears

Ahead of its IPO, Anthropic told investors Q3 revenue reached $16.8B (up from $11.5B in Q2), with $1.70 earned per $1 of compute spend and 11% adjusted operating margins. Distillation by rival labs accounted for 5–7% of revenue before being cut back 'materially' in Q3.

"The disclosed economics — near-profitability, hyperscale growth, and competitors spending over half a billion dollars distilling its models — quantify just how central Claude has become to the AI ecosystem."
