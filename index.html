AI Models & Research

Claude Autonomously Discovers Novel Cryptographic Weaknesses in 60-Hour Research Session

Anthropic researchers revealed how Claude Mythos autonomously found mathematical flaws in both HAWK and a weaker version of AES over a 60-hour session costing an estimated $100,000 in compute. The primary human interventions involved prompting the model not to give up and encouraging it to find something worthy of publication, resulting in a new eval benchmark created in partnership with ETH Zurich and other universities.

"This demonstrates the viability of using frontier models as persistent, autonomous research agents capable of executing long-horizon scientific tasks that require deep reasoning and overcoming repeated failures."

Developer Tools & Infrastructure

Google Ships Environment Hooks and MCP Support for Gemini Managed Agents

Google's Gemini API Managed Agents now includes environment hooks, allowing developers to run custom validation scripts directly inside the agent's remote sandbox before or after tool executions. The update also brings Gemini 3.6 Flash as the default model, budget controls to cap token usage, scheduled triggers, and an Environments API for better lifecycle management.

"Environment hooks and robust cost controls solve critical pain points in agent orchestration, giving developers the ability to enforce guardrails and automate validation within ephemeral cloud execution environments."

WorkOS Releases Remote MCP Server to Let Agents Manage Infrastructure

WorkOS launched a remote Management MCP server that allows AI agents like Claude Code and Cursor to autonomously configure domains, manage users, and debug sign-in issues using existing dashboard permissions. The server uses a discover-then-execute design pattern to efficiently manage context limits, while deliberately excluding dangerous operations like credential minting and user impersonation.

"By exposing complex administrative surfaces as MCP tools, WorkOS is enabling a new wave of enterprise IT automation where agents can securely manage infrastructure without human dashboard intervention."

Together AI Introduces Capacity-Aware Routing for Model Inference Rollouts

Together AI detailed its new Dedicated Model Inference resource model, which decouples stable endpoints from disposable deployments using capacity-aware traffic routing. This architecture allows autoscaling to dynamically adjust traffic loads based on ready replicas, enabling seamless zero-downtime changes, A/B testing, and shadow experiments for agentic workloads.

"As agent workloads introduce highly variable inference demands, this routing architecture provides developers with a robust way to balance latency and throughput during live model transitions."
