HalluSquatting Exploit Weaponizes AI Coding Agents for Mass Botnets

Security researchers have uncovered 'HalluSquatting,' a novel pull-based prompt injection attack that exploits AI coding assistants' tendency to hallucinate resource identifiers. By predicting and registering malicious packages that agents are likely to fetch, attackers can potentially assemble massive botnets through tools like Cursor, GitHub Copilot, and Windsurf.

"As agentic coding tools gain autonomous access to high-privilege command lines, this vulnerability highlights a critical blind spot in how models fetch and execute third-party resources at scale."
